# Манифест со стороны кода — 2026-11-12 (фаза A брифа агента)

Что доступно из сессии на VPS и что нет. Ожидаемое API компонентов теперь целиком лежит в `docs/ds-manifest.json` (оси, значения, свойства с типом и значением по умолчанию, вложенные компоненты, токены по слоям); таблица из `docs/dsp-check-2026-11-09.md` остаётся как краткая выжимка по изменённым 09.11.

## Доступно
- `tokens/**`, `build/css|js|json` — экспорт Foundations `14cd245` (2026-11-09). Сверка с манифестом Figma: из 210 токенов, использованных в компонентах, в репо нет 20 (список — `docs/audit-2026-11-12.md`, раздел 3). Причина: заведены в Foundations 09.11 после экспорта, Publish и экспорт не сделаны.
- `claude-ds/components/` — только Button; `claude-ds/status.json` приведён к Figma 12.11 (Badge, Checkbox, Chip, Input, Radio, Textarea, Toggle → beta).

## Недоступно
- DSP (плагин и сайт), MR DSP Export, репо Vue (`ui-emcd-web`), `ds-playground`, Storybook, Flutter-JSON: доступа из сессии нет, клонировать запрещено брифом. Сверку делает разработчик или Стефан по манифесту.

## Как сверять, когда доступ появится
1. Из кода получить список: компонент → props (имя, тип, значения, значение по умолчанию) → использованные CSS-переменные.
2. Сравнить с `docs/ds-manifest.json`: `axes` и `props` ↔ props; `tokens` ↔ переменные. Скрипт `scripts/parity.mjs` (фаза D) примет оба файла и выдаст расхождения; до появления манифеста кода он проверяет только Figma ↔ `tokens/**`.
3. Имена: ось Figma `Label position` → prop `labelPosition`; булево `Show label` → `showLabel`; слот `Leading` → слот `leading`. Служебные свойства Figma (`Focus ring`, `Show hit area`, `Safe margin`) в код не идут.
