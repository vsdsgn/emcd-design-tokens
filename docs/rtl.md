# RTL (арабский) в DS 2.0 (черновик, 2026-10-19)

RTL — базовое требование, не фича бренда: интерфейс обязан выдерживать арабский на уровне компонентов, иконок и шрифтов. Языки и общие правила — в typography-l10n.md.

## Что зеркалится, что нет

| Зеркалится | Не зеркалится |
|---|---|
| раскладка: «начало» справа, порядок элементов в строке; логические отступы (`margin-inline-start`, `EdgeInsetsDirectional`) | графики, оси времени, числа, суммы, тикеры (изоляция направления: `<bdi>` / `unicode-bidi: isolate`) |
| сторона контрола у Checkbox / Radio / Toggle (свойство `Control` Left ↔ Right); иконка слева от подписи → справа | иконки без направления: плюс, галочка, закрыть, часы, глаз, замок, меню, поиск и др. |
| направленные иконки (список ниже), «назад» / «вперёд», шевроны | медиа-кнопки, логотипы, QR, адреса кошельков, коды |
| выравнивание текста по началу строки, табы, хлебные крошки, пагинация, шаги | порядок цифр (латинские цифры: `ar-u-nu-latn`) |

## Иконки (Icons, 121 шт.)

Помечены в описании как «RTL: зеркалится»: `arrow-left`, `arrow-right`, `chevron-left`, `chevron-right`, `arrow-exit`, `arrow-new-tab`, `send`, `list`.

На решение Стефана (спорные): `history`, `chat`, `play`, `search`, `trend-up`, `refresh` / `renewal` / `repeat`. По умолчанию не зеркалим: платформенные гайды расходятся.

## Ограничения Figma (по форуму Figma на конец 2025)

- Направление текста RTL в интерфейсе Figma есть, в Plugin API его нет; перенос в auto layout wrap справа налево не поддерживается; выравнивание текста не переменная. Поэтому режим `Locale samples` меняет только строки, а раскладка зеркалится вручную.
- Принятый обходной путь: свойства направления в самих компонентах (`Control` Left / Right у контролов), в остальных — отдельные RTL-кадры вручную на бордах.

## Как проверяем

- На бордах компонентов — блок «12 · Локали и RTL»: 9 режимов (en · ru · de · ar · th · ja · hi · long · short); в режиме `ar` у контролов показана зеркальная сторона.
- Для экранов (организмы, виджеты, лейауты) — отдельная тестовая доска, когда они будут.
- В коде: `dir="rtl"` на корне, логические свойства CSS; во Flutter — `Directionality` и `*Directional` отступы.
