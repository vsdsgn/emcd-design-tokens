# Компоненты DS 2.0 — правила устройства

## Свойства или слоты

Компонент не должен становиться «монстром» с десятками свойств и скрытых слоёв. Правило:

- **Свойства (variant, boolean, text, instance swap)** — для того, что у компонента **всегда одинаково по смыслу**: размер, иерархия (primary / secondary / tertiary), состояние, тон (danger), наличие иконки.
- **Слоты** — для областей, где **содержимое меняется от места к месту**: туда кладут что угодно из системы, а компонент отвечает только за раскладку и отступы.

| Компонент | Слоты | Остаётся свойствами |
|---|---|---|
| Input / Select / Search | prefix (иконка, монета, валюта), suffix (единицы, «Max», кнопка), hint/helper | size, state, label, error |
| List item | leading (иконка, аватар, монета), content (одна-две строки), trailing (значение, статус, шеврон, переключатель) | size, interactive, divider |
| Card / Section | header actions, body, footer | padding, elevation |
| Side panel / Sheet / Modal | header actions, body, footer (кнопки) | presentation, size |
| Page header | actions (кнопки, период, фильтры) | title, counter, back |
| Shell | nav, promo, balance, profile | platform, collapsed |
| Empty state | illustration, actions | title, text |
| Table cell | custom content | align, numeric |

**Не слоты:** Button, Checkbox, Radio, Toggle, Chip, Badge — у них анатомия фиксированная, иконка меняется через instance swap.

### Правила слота

- У слота есть **содержимое по умолчанию** — чтобы компонент выглядел готовым без настройки.
- Отступы и выравнивание внутри слота задаёт **компонент токенами**, а не то, что в него положили.
- В слот кладут только компоненты системы (или текст) — не отвязанные куски.
- В коде слот = slot во Vue, параметр-виджет во Flutter, children/props в React. Имена слотов совпадают с Figma.

## Описание компонента (description)

```
<что это, 1 строка по-русски>
Когда использовать: … / Когда нет: …
Поиск: ru-синонимы, en-синонимы, то же в неправильной раскладке
Legacy: старые имена компонента
```

## Доступность: клавиатура, VoiceOver / TalkBack, переключатели

Закладывается в **каждый** компонент и пишется в его описании строкой `A11y:`.

### Фокус

- Видимый фокус — **кольцо снаружи компонента**: 2px прозрачного зазора, затем обводка 2px `border/focus`. Скругление кольца = скругление контрола + 4 (`radius/focus-ring`, `radius/focus-ring-sm`). В коде: `outline: 2px solid var(--border-focus); outline-offset: 2px;`. Во Flutter — отдельный декоратор поверх контрола с тем же отступом.
- Показывается только при управлении с клавиатуры / переключателя / VoiceOver (`:focus-visible`), не при клике мышью или тапе.
- В Figma — состояние `State=Focus` у интерактивных компонентов.
- Порядок фокуса = порядок чтения (сверху вниз, слева направо). Модалки и шторки **запирают** фокус внутри, при закрытии фокус возвращается на элемент, который их открыл.
- Первый элемент страницы — «Перейти к содержимому» (skip link), невидимый до фокуса.

### Клавиатура (базовые правила)

| Элемент | Клавиши |
|---|---|
| Кнопка, ссылка | Tab — фокус, Enter (+ Space для кнопки) — действие |
| Checkbox, Toggle | Space — переключить |
| Radio, Segmented, Tabs | ←/→ (↑/↓) — переход внутри группы, Tab — выход из группы |
| Select, Dropdown menu | Enter/Space/↓ — открыть, ↑/↓ — выбор, Enter — подтвердить, Esc — закрыть |
| Modal, Sheet, Side panel, Popover | Esc — закрыть, фокус заперт внутри |
| Table | Tab — по интерактивным ячейкам/строкам, Enter — открыть детали |
| Slider | ←/→ — шаг, PageUp/PageDown — большой шаг, Home/End — края |

### Экранные читалки (VoiceOver, TalkBack)

- У каждого интерактивного элемента есть **доступное имя**: текст подписи или `aria-label` (для кнопок-иконок — обязательно, совпадает с tooltip).
- Роль и состояние озвучиваются: `aria-pressed`, `aria-expanded`, `aria-selected`, `aria-checked`, `aria-disabled`, `aria-busy` (loading), `aria-invalid` + связанная ошибка (`aria-describedby`).
- Динамические сообщения (Toast, ошибки форм, статусы загрузки) — через live region (`role="status"` / `alert`), без перехвата фокуса.
- Иконки-декорации скрыты от читалок (`aria-hidden`), смысловые — с подписью.
- Суммы и крипто: читалке отдаётся полная форма («0,00143210 LTC, примерно 64 доллара»), адрес — целиком, а не с многоточием.
- Flutter: `Semantics(label, button: true, …)`, порядок — `SemanticsSortKey`; iOS/Android-жесты VoiceOver/TalkBack не перехватываем.

### Размеры и движение

- **Hit area зашита в компонент**: невидимый слой `hit area` высотой не меньше `touch/min` (Web 24, App 44), по центру. Если контрол меньше (S 32 в App), область нажатия выходит за его границы, визуально ничего не меняется. В коде: hit area = max(размер, touch/min) — в вебе через `::before` с отрицательным inset, во Flutter через `minimumSize` / `MaterialTapTargetSize.padded`. Соседние интерактивные элементы не должны перекрывать hit area друг друга (зазор между ними ≥ разницы).
- `prefers-reduced-motion` — анимации переходов заменяются на мгновенные или fade; спиннер — пульсацией.
- `prefers-reduced-transparency` — без блюра (см. effects.md).
- Текст масштабируется до 200% без поломки (rem в вебе, системный text scale во Flutter).
