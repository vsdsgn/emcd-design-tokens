## Токены репо (14cd245)

- `os/safe-area/top|bottom|left|right` в Platform есть: CSS `--os-safe-area-*`. iOS top 59 / bottom 34 → `3.6875rem` / `2.125rem`, Android 24 / 24 → `1.5rem`, Web и Mobile web 0, left / right 0. Конвейер хранит их в rem, как все размеры; в коде брать системные insets, не эти числа.
- Шесть Deprecated-токенов Theme (`action/tertiary/hover|pressed`, `surface/hover|active`, `control/segment-hover`, `action/secondary/hover`): метка лежит только в описании переменной в Figma; в `tokens/**` и `build/**` её нет. В MR проверить, что все шесть помечены deprecated и не удалены.
- `--control-safe-margin` есть (Web 8); свойство «Show safe area» в Figma ещё не переименовано.

## Расхождения для отчёта

1. Toast: в задаче и в OPEN-QUESTIONS 2026-11-05 — `Layout = Card | Header`, в Figma — `Card | Informer | Snack`. Источник правды — Figma.
2. Свойства Table header cell / Table cell · Buttons и «Safe margin» в Figma ещё не обновлены, API там не окончательное.
3. Deprecated-метки не видны в репо (только в Figma) — проверка только по MR DSP.
