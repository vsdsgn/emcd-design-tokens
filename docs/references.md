# Референсы DS 2.0 — что откуда брать

Основа не меняется: наш скилл design-studio (правила и его референсы), токены DS 2.0, legacy DS и продукты. Всё ниже — **дополнительные** библиотеки: подсматривать поведение и детали, когда наших источников не хватает. Значения всегда наши.

- Arc UI — подсказки по состояниям, клавиатуре, доступности и движению продуктовых компонентов.
- Componentry, Space UI, Skecher UI, Planes — идеи для выразительного слоя (промо, сайт, онбординг, AI-сценарии); не в рабочих экранах.

## Arc UI (uiarc.dev) — где может пригодиться

144 компонента и 84 блока, у каждого markdown-спецификация: when / when not, props, keyboard, accessibility, motion, responsive. Индекс: uiarc.dev/llms.txt.

| Наша задача | Arc | Что берём |

### Правила движения, взятые у Arc (дополняют motion.md)

- **Пружины для прерываемого**: `smooth` 0.4 s, bounce 0 — панели, высота, переключатель, прогресс; `snappy` 0.26 s, bounce 0.12 — нажатия, мелкие индикаторы; `morph` 0.42 s, bounce 0.16 — скользящая подсветка (табы, сегменты). Всё, что показывает состояние, — без отскока.
- **Кнопка, открывающая меню/поповер, не сжимается** при нажатии — только цвет (иначе меню позиционируется от уменьшенного размера).
- **Одно непрерывное движение** на взаимодействие, не «проявление, потом сдвиг, потом масштаб».
- **Числа докручиваются** до нового значения, `tabular-nums`, фиксированная ширина.
- **Подтверждение действия на переднем плане — на месте** (кнопка → «Сохранено»), без тоста. Тост — для фоновых результатов.

## Выразительный слой

| Источник | Для чего у нас | Границы |
|---|---|---|
| Componentry (componentry.dev) | промо-герои сайта, лендинги продуктов (Coinhold, Geometria), сторителлинг | только Site и Media & Promo |
| Space UI (spaceui.one) | AI-сценарии (ассистент), лоадеры ожидания, выразительные слайдеры в промо | не в формах и таблицах |
| Skecher UI (skecher-ui.com) | микровзаимодействия онбординга, анимация текста заголовков, AI-чат | одно выразительное место на экран |
| Planes (useplanes.com) | логины, промо-блоки, command palette; модель «agent-ready» (MCP + llms.txt) | шейдеры и физика — только промо |

Обязательно для всего выразительного: `prefers-reduced-motion` → статичная версия; режим Lite (`data-perf="low"`) → без WebGL и blur; брендовые цвета только из токенов.

## Agent-ready: что берём для самой DS 2.0

Arc и Planes отдают агентам `llms.txt` и markdown на каждый компонент. У нас описания компонентов в Figma уже устроены так же (когда / когда нет / правила / A11y / поиск / legacy). План: выгружать их скриптом в `docs/components/<name>.md` + `llms.txt` в репо — это вход для Claude Design и для Claude Code при вёрстке.
