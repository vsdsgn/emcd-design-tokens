## По компонентам
- Checkbox / Radio / Toggle: сломаны RTL и локали.
- Chip: плашка в превью полностью круглая (проверить); два размера — решить на живых примерах; иконка слева и справа; закрываемый чип (тег) по желанию; используется как табы.
- Icon button / Button: floating / sticky в правилах; Tooltip пересмотреть.
- Card: Level 0 забыт; отступы и скругления — примерять на интерфейсах; слетели «Код и токены» и анатомия; safe-зоны не нужны.
- Tab: слетело превью, фокус плохой; Hover и Pressed разные (☑ серая полоска снизу, 19.10); hit area высоковато; правила отступов между табами; схлопнуть борды Tab и Tabs.
- Segment / Segmented: ☑ тени убраны из Base (19.10, Expressive позже); автолейауты, таблицы; примеры.
- Spinner / Progress / Progress circle: circle — тот же Progress (виды line, circle, с процентом); Spinner — отдельный лоадер рядом со Skeleton с правилами; в Progress съехали таблицы и размеры.
- Skeleton: всё поехало; градиент по диагонали и шире.
- Badge / Counter: съехала сетка превью и размеры; иконка слева и справа; фокус возможен; Counter, Badge и точка нотификации — группа.
- Status: серый в светлой теме слишком тёмный; точка и точка с подписью; общий dot — рассмотреть.
- Divider: нет dotted; правила: растягивается, между чем, как вставляется.
- Avatar / Avatar group: в Image съехал слой и нет изображения; индикаторы вокруг; группа: обводки в цвет фона, последний «+N», без прозрачности; две борды в одну.
- Scrollbar: примеры, min / max, таблицы и превью; Fade и Progressive Blur — не вижу.
- Page dot / Page indicator: нет полных примеров и анимаций; таблицы съехали.
- Legend swatch: не нашёл на странице; Crosshair слетел полностью — правила, safe-зоны, курсор, взаимодействие с графиком, несколько серий; графики без линий (только hover); много работы по графикам.
- Step symbol / Stepper: чёрная иконка на зелёном; обводки и плашки светлее; другие степперы: полоски, точки, вертикальные и горизонтальные.
- Pagination / Date cell: календарь как организм Date picker (одиночный, двойной, шорткаты, кнопки по бокам, из старых DS).
- Breadcrumb: вёрстка, правила, фокус, воздух, максимум, сокращения.
- Code cell / Code input: таблицы, раскладки, правила, анимации.
- Tab bar / Tab bar item: мобильный; мульти-кнопка вместо айтема; min / max; точки нотификаций; фокус на мобильном вебе.
- Не трогали: Stat card, Table, Chart (ок), Step progress (старый), Slider, Accordion, List item.
- Бейджи и фокус: «бейдж не фокусируется» — неверно, для voice-over и веба фокус нужен.
