# Правила построения: компоненты, конструкции, лейауты

Карта: где лежит каждое правило, в каком порядке собираем и чего пока не хватает. Сами правила здесь не дублируем: источник — документ, на который ведёт ссылка. Правила поведения агента — `docs/RULES.md`, ошибки — `docs/LESSONS.md`.

## 1. Порядок сборки (обязателен)

1. **Эталон.** Снять прод и макеты Figma до начала. Порядок по слову Стефана: сначала экраны, потом прод. Отклонения от прода — осознанно и с записью (L-023).
2. **Перечень сценариев.** Составить и сверить со Стефаном; вопросы вынести на борду «⚑» до рисования (L-031).
3. **Библиотеки.** Искать нужное в опубликованных Components, Icons, Illustrations, Symbols. Нет нужного — добавить в библиотеку и опубликовать. Локальных компонентов на экранах не заводим (L-025).
4. **Компонент.** Общий дефект — правим компонент, Стефан публикует (L-027). Только после Publish — экраны.
5. **Экран.** Собираем из компонентов и токенов; размеры, отступы и слои — по разделам ниже.
6. **Аудит.** `layout-audit.plugin.js` до 0 замечаний, затем чеклист `docs/patterns.md` §0.3 глазами в полном размере (L-038). После каждого Publish — повтор по экранам (L-034).
7. **Отчёт по списку.** Замечания Стефана — нумерованный чеклист, в отчёте каждый пункт (L-022).

## 5. Вход, регистрация, 2FA

- В `main` есть только §4.6 «Авторизация» — по старой схеме (карточка 585 × до 770).
- Актуальные правила (§3.15: заголовки, размеры, окна и шторки, слои мобильных шагов, Toast по платформам, иллюстрации, 2FA) написаны в ветке `claude/registration-flow-all-states-73f1c8` и **в `main` не влиты**. Контракты Button, Toast, Suggest, Input и запись в `CHANGELOG-components.md` — там же.
- До мерджа правилами для флоу считать ветку, не `main`.

## 6. Дыры и противоречия (нужны решения)

1. **§3.15 не влит в `main`**, а §4.6 в `main` устарел.
2. **Размеры полей и кнопок:** §0.0 — «L 48 только главная форма шага»; §3.15 (ветка) — в одном пункте «Web — Input M, Button M», в другом «Input L (56) и кнопки XL у всех платформ». Нужно одно правило.
3. **Заголовок шага:** `CHANGELOG-components.md` (ветка) — «Web Heading/XL (32), Compact Display/MD»; §3.15 — «Display/MD на всех платформах».
4. **Toast Informer:** «накладывается, контент не сдвигается» против «в потоке и сдвигает контент» (оба в ветке).
5. **Размер модалки:** §6.3 — Modal sm 400 / md 560; §3.15 (ветка) — 440 × 600; §4.6 — `size/modal/md` 560 (предложение).
6. **Нет правила для** положения cookie-баннера и виджета поддержки в `main`, порядка способов входа (в ветке: почта и телефон основные, на проде иначе — решение Стефана), единого размера окон сценария в общем разделе.
7. **Автопроверок нет** для: роль заголовка → стиль, локальные компоненты на экране, подложка подписи Input = фон контейнера (L-024, L-025, L-030).

Закрытая дыра — удаляется из этого списка в том же коммите, который её закрыл.
