## 2. Intent
- Индикатор страниц карусели: ряд точек, текущая — вытянутая.
- Когда использовать: карусель из 2–5 слайдов — промо, онбординг, сторис-баннеры.
- Когда нет: больше 5 слайдов — счётчик «3 / 12»; шаги процесса — Stepper / Step progress.
- Правило выбора варианта:
  - Count: 2–5 — по числу слайдов.
  - Selected: номер текущего слайда, не больше Count (матрица 14 из 20). Выбрана ровно одна точка.
  - Место: по центру под каруселью, отступ `space/12`; на изображении — поверх затемнения.
- Не делаем: больше 5 точек; на пёстром фоне без затемнения; две выбранные точки.
