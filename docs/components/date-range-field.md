## 2. Intent
- Поле выбора диапазона дат: подпись на рамке, значение «ДД.ММ.ГГ → ДД.ММ.ГГ», справа иконка календаря. По нажатию открывает панель с календарём (Calendar, Mode=Range) и пресетами периодов.
- Когда использовать: выгрузки, фильтры по периоду, отчёты.
- Когда нет: одна дата — Input с календарём; быстрый выбор («7 дней», «30 дней») — Chip или Segmented.
- Правило выбора варианта:
  - State: Default — пусто, плейсхолдер формата; Focus — поле активно, панель открыта или идёт ввод; Filled — период выбран; Error — период не прошёл проверку (после выбора); Disabled — выбор недоступен; Hover — указатель над полем; Skeleton — форма грузится.
  - Ограничение периода показывается в подсказке до выбора, ошибка — после; одновременно — одно сообщение.
  - Формат даты — по локали (дд.мм.гг в ru); стрелка между датами направленная; ввод с клавиатуры допустим.
  - База — Input Size=M, Label position=On border; длинная подпись — Label position=Above. Ширина не меньше `size/field/min` (160).
- Не делаем: ограничение периода только в тексте ошибки; дефис или другой ненаправленный разделитель между датами.

## 3. Anatomy
- Корень — экземпляр Input (Size=M, Label position=On border), min-width `size/field/min`: подпись на рамке (`notch text` в `_Field base`, одна строка ≤ 240), значение, подсказка / ошибка под полем.
- Справа — Input addon / Icon с `icon/calendar`.
- Своих служебных слоёв нет: кольцо фокуса, зона нажатия и безопасное поле — из Input.
- Вложено: `Input` ×7.
- Служебные слои (вариантов из 7): кольцо фокуса 0 · зона Web 0 · зона касания 0 · безопасное поле 0.

## 4. States
- Группа модели состояний (`docs/components.md`): Поле ввода: состояние — цветом рамки и сообщения; Hover — обводка `control/border/hover` + слой; Disabled — токены `*/disabled`; Skeleton — загрузка (всё из Input).
- Default — плейсхолдер «ДД.ММ.ГГ → ДД.ММ.ГГ», под полем подсказка.
- Focus — тёмная рамка и каретка в начале значения.
- Filled — выбранный период основным цветом текста.
- Error — красная рамка, сообщение об ошибке вместо подсказки.
- Disabled — серая заливка; подпись, значение, подсказка (`text/disabled`) и иконка календаря (`icon/disabled`) погашены.
- Hover — обводка `control/border/hover` и слой состояния; Skeleton — плашка вместо поля (оба — через вложенный Input).

## 6. Content / slots
- Значение — две даты в формате локали и направленная стрелка между ними; подпись — что за период («Период»); подсказка — ограничение («Выгрузить можно за 3 месяца, но в рамках года»).
- Длинный текст: значение и плейсхолдер — одна строка, многоточие; подпись на рамке — одна строка ≤ 240 с многоточием, длинная подпись — Label position=Above; подсказка и ошибка переносятся.
- RTL: стрелка между датами зеркалится, иконка календаря — в начале поля; цифры не зеркалятся.
- Языки (стенд): de, ar, hi, th, ja, kk — без обрезки по высоте.
- Текст 200 %: значение усекается многоточием, подсказка и ошибка переносятся; подпись на рамке налезает на значение, высота поля не растёт (база `_Field base`, см. todo). В коде — `min-height` поля и подпись On border при увеличенном шрифте переходит в Above (рекомендация `_Field base`).

## 7. Events
- `click` по полю или иконке — открывает панель (Calendar, Mode=Range, пресеты периодов).
- `change` — выбран период (обе даты) в панели или введён с клавиатуры.
- Esc — закрывает панель, фокус возвращается на поле. У Disabled событий нет.

## 8. Behavior
- Проверка периода — после выбора: State=Error и текст ошибки вместо подсказки.
- Рамка и её отклик — из Input; панель — по правилам Calendar.

## 9. Accessibility
- `role=group` с подписью; две даты — два связанных поля (начало и конец).
- Панель — `role=dialog`; Esc закрывает, фокус возвращается на поле.
- Подсказка и ошибка — `aria-describedby`; ошибка различается не только цветом — текстом.
- Кольцо фокуса — только при навигации с клавиатуры, появляется сразу, без анимации (`service-layers.md`). Кольцо и зона нажатия — у вложенного Input.
