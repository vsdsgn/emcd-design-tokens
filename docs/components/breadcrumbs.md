## 2. Intent
- Путь к текущей странице в глубокой иерархии (Web): «Главная / Воркеры / rig-01».
- Когда использовать: 3 и более уровня вложенности; стоит над заголовком страницы.
- Когда нет: плоская навигация; App и Compact — там «назад» в Top bar.
- Правило выбора варианта:
  - Items: 2 / 3 / 4 — по числу уровней пути; Collapsed — первый пункт, «…» и два последних.
  - Длинный путь: больше 4 уровней или не помещается в ширину — Collapsed; «…» — кнопка, открывает Menu со скрытыми уровнями.
  - Последний пункт — текущая страница (Breadcrumb item State=Current), не ссылка; остальные — ссылки.
  - Разделитель — один на всю систему («/»).
- Не делаем: крошки в App и Compact; ссылка на текущей странице; свой разделитель; больше 4 видимых пунктов; перенос на вторую строку.

## 6. Content / slots
- Длинный пункт: подпись — одна строка ≤ 200 с многоточием (Breadcrumb item), полное название — в тултипе. Ряд целиком не сжимается: не помещается — Collapsed.
- Языки: de, ar, hi, th, ja, kk — обрезки по высоте нет.
- RTL: порядок пунктов зеркалится (текущая страница — слева); названия не зеркалятся. На стенде направление не переключается.
- Текст 200 %: ряд растёт вместе с кеглем, обрезки и наложений нет.

## 7. Events
- `click` по пункту-ссылке — переход на уровень; по «…» — открыть Menu со скрытыми уровнями, выбор пункта — переход. У текущей страницы событий нет.

## 8. Behavior
- Статичен; переход — навигация, без анимации самого компонента.
- Collapsed: Menu со скрытыми уровнями открывается от «…».

## 9. Accessibility
- `nav` с `aria-label` «Хлебные крошки», внутри список `ol`; текущая страница — `aria-current=page`.
- Разделители скрыты от читалки.
- Клавиатура: Tab — по ссылкам, Enter — переход; текущая страница в порядок фокуса не входит.
- «…» — кнопка с доступным именем и `aria-expanded`; Enter / Пробел — открыть Menu, ↑/↓ — выбор, Enter — переход, Esc — закрыть.
