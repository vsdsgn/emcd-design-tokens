## 2. Intent
- Кирпичи скелетона: из них собираются Skeleton-состояния всех компонентов с данными (List item, Table row, Stat card, Chart card, Coin, Avatar).
- Когда использовать: загрузка данных дольше 1 с, форма будущего контента известна.
- Когда нет: идёт действие — Loading у кнопки; до 300 мс — ничего не показываем; 300 мс–1 с — Spinner; известная длительность — Progress.
- Правило выбора варианта:
  - Shape — по форме будущего контента: Text — строка текста; Title — заголовок; Circle — аватар, монета, иконка; Rect — картинка, график, блок; Button — кнопка; Input — поле; Chip — чип, бейдж.
  - Все скелетоны экрана — с одним общим бликом.
- Не делаем: скелетон не в форме контента; несинхронный блик у соседних скелетонов.
