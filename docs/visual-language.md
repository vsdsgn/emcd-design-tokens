# Визуальный язык EMCD (черновик, 2026-10-04)

Наглядно: Foundations → «🌗 Visual language».

Опоры: Apple — Liquid Glass только в функциональном слое, не в контенте, не наслаивать; Fluent 2 — материалы solid / mica / acrylic / smoke, акрил для временных поверхностей, сплошной откат; HarmonyOS 7 — уровни материала, адаптивный откат на слабых устройствах к фону, обводкам и теням, материал только в разрешённых зонах навигации.

Один словарь эффектов для всех продуктов. Expressive — полный язык (pool, Monitoring), Base — тот же язык без декора. Иконки: один набор DS (каркас Lucide); Expressive добавляет обработку слоями внутри компонента, не отдельный набор.

## Предлагаемые единые значения

| Роль | Токен | Значение | Правило |
|---|---|---|---|
| Пятно фона | `style/glow/blur` + `style/glow/<tone>` | одно: 160 | ≤ 1 на экранную зону, только у ключевой сущности или статуса |
| Свечение иконки (навигация, выбранное) | `style/glow/sm` (новый) | 16, бренд | только активный пункт навигации / выбранный элемент |
| Градиентная кромка | `style/edge/accent` → `border/subtle` | одно направление, 1 px | активный пункт навигации, выбранная/рекомендуемая карточка |
| Стекло | `effect/blur/glass-sm|md|lg` | 8 / 16 / 32 | только плавающие и липкие: шапка, сайдбар, таббар, оверлеи |
| Тень | `shadow/*` (есть) | 2 уровня | только плавающие элементы; на карточках тёмной темы — нет |
| Линия-кромка | `effect/edge-top` (есть) | 1 px | верхний край стекла / панелей App |
| Волосок | `border/glass` | белый 8% / чёрный 8% | карточки Expressive |
| Тинт | `style/card/tint` | бренд 16% → 0 | герой-карточки (баланс, хешрейт, промо) |
| Иллюстрации | — | ассеты | библиотека иллюстраций, не токены |

## Роли (принято в работу)

| Группа | Токены | Где разрешено | Откат |
|---|---|---|---|
| Материалы | `material/thin|regular|thick/fill|blur`, `material/scrim` | thin — липкие шапка, таббар; regular — сайдбар; thick — меню, поповеры, шторки; scrim — под модалкой | сплошная заливка |
| Свет | `light/ambient`, `light/status/*`, `light/accent`, `light/tint` | ambient — герой-зона; status — карточка статуса; accent — активное/выбранное; tint — герой-карточки | нет |
| Кромки | `edge/hairline|accent|highlight` | hairline — карточки; accent — выбранное; highlight — с материалом | обычная обводка |
| Глубина | `Elevation/1–4` | только плавающее | те же тени |

Бюджет экрана: ≤ 1 пятна фона в зоне видимости; пятно статуса — одно на карточку и только для статуса; свечение иконки — только у выбранного; материалы не наслаиваются; в слое контента материалов нет. Пятно: блюр один (160), размер — доля контейнера (~60 % ширины, constraints Scale).

## В коде: пятно фона без filter: blur

`light/ambient` в вебе рисуем `radial-gradient(closest-side, var(--light-ambient-color), transparent)` на элементе ~60 % контейнера, а не `filter: blur(160px)`: дешевле и без полос в WebKit. `light/ambient/blur` остаётся для Figma.
