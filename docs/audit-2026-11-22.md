## 3. Одна база — разные наборы (на решение)
| Сейчас | Предложение | Почему |
|---|---|---|
| **Avatar** (XS 20 / S 32 / M 40 / L 56; Text · Icon · Image) и **Coin** (XS 16 … XL 40; Network) | один `Avatar`: Type = Text · Icon · Image · Coin, общая шкала размеров 16 / 20 / 24 / 32 / 40 / 56, бейдж сети — свойство | одна форма (круг, медиа, скелетон), разные шкалы размеров сейчас не совпадают |
| **Avatar group** и **Coin stack** | один `Avatar group` (Type как у Avatar, Count, More) | одинаковое наложение с обводкой |
| **Spinner**, **Progress circle**, **Circle timer** | один `Progress circle`: Mode = Indeterminate · Determinate · Timer (как у `Progress`) | одно кольцо, разные режимы |
| **Toast** и **Snack** (draft) | `Toast` Layout = Card · Informer · Snack | одно сообщение поверх экрана |
| **Checkbox group**, **Radio group**, **Toggle group** | `Selection group`: Type = Checkbox · Radio · Toggle | одинаковая анатомия: подпись, список, helper, ошибка |
| **Legend swatch**, `_Dot` | одна база `_Marker`: Shape Dot · Line, цвет Tone (статусы) или Series (графики) | одна точка 6–8 |
| **Counter** и **Badge** | Counter — Badge Type = Count (только число, квадрат) | одна плашка, разная подпись |
| **Select compact** и **Select** | оставить два набора, но на одной базе `_Field base` (сейчас compact — своя вёрстка) | разная анатомия (без подписи), общий вид поля |
| **Card**, **Promo card**, **Stat card**, **Radio card** | проверить, что все — на вложенной `Card` (уровень, радиус, отступ — от неё) | один способ сделать поверхность |

Слияние наборов — MAJOR (меняются экземпляры в продуктах): делается заменой на месте (`swapComponent` по всем файлам Migration test), старый набор — в архив после «ок».
