# Бэклог дефектов стенда (править в Figma после сбора всех групп)
## Группа 1
- Circle timer: iOS / Android, Size=M — `progress` не растёт с треком (нет привязки w / h).
- Code cell: Empty / Focus показывают «4» (свойство Digit) вместо плейсхолдера «0»; `digit` не ограничен (clip).
- Coin: `network` с кольцом выходит за корень (проверить; решение — исключение или вместить).
- Date cell: Disabled не зачёркнут, неотличим от Outside.
- Divider: Label=On — линии на дробной координате (бледные); Dotted — `border/default` вместо `border/subtle`; нет правила для Style.
- Legend swatch: линии Series 5–8 без штриха (описание обещает).
- Chart axis label: 200 % усечение «14:…» (заметка, решение); Legend swatch описание chart/series/* vs data/*.
- Multiselect option: порядок вариантов; правило длинной подписи.

## Группа 2 (стенд 2026-11-13)
- Page dot: Selected=On — `icon/primary` (чёрная / белая) во всех брендах, описание обещает цвет акцента. Свести заливку и описание.
- Pagination item: длинное Page не расширяет плашку (ширина корня фиксирована 32 / 40), описание: ширина растёт с числом → Hug + min-width.
- Progress: `label row` ломается на длинном тексте и на 200 % (value на всю ширину, label в столбик по букве). Задать правило длинного текста, поправить раскладку (label Fill + усечение, value Hug).
- Progress circle: 200 % у Size=M — «60%» налезает на кольцо (заметка / правило: значение в M не масштабируется выше кольца).
- Scrollbar (?): Hover и Dragging почти неотличимы — усилить различие thumb или записать в описании.
- Skeleton: описание противоречит себе — блик 1.2 с (решение 2026-10-31) против Motion 1.5 с; reduced motion: пульсация против статичной заливки. Свести описание.
- Step symbol: описание называет Active, ось — Current; длинное Number выходит за круг (ограничить 1–2 цифры в описании или clip).
- Step trail: в описании Active вместо Current.
- Заметки: Step segment акцент `icon/accent` против `control/checked` у Step symbol / trail; Step symbol Bullet Default и Step trail Default в Dark L0 почти не видны; Overlay Blur на пустом фоне не проверить; Spinner Size=M корень `icon/size/control`, дорожка `icon/size/md`; нет строки Legacy у Page dot, Pagination item, Step segment, Skeleton; Pagination item — нет варианта «…».
