- Informer на iOS / Android выше, чем на Web: сверху поле `os/safe-area/top` (iOS больше Android, на Web 0) — по описанию, не дефект.
- ? Dark: `surface/raised` (#1a1a1a) совпадает с фоном L1 и темнее фона L2 / L3 (лист 08–09) — карточка отделяется только тенью; обводки `border/subtle` на снимке не видно. Вопрос уровня Foundations (подъём поверхностей в Dark), не набора.
