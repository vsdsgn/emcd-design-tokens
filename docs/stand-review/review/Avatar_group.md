## Заметки (не дефект / на решение)
- More=On: «+3» — круг того же размера, текст `text/primary`, читается во всех темах и брендах; порядок A B C D +3, нахлёст ровный у XS / S / M.
- «Текст · long / de / ar / hi / th / ja / kk»: своих текстовых свойств нет, стенд подменил инициалы вложенных Avatar — длинный текст обрезается кругом (как у Avatar: инициал — 1 буква, усечение в коде). Показан только вариант по умолчанию (XS, More=Off).
- Geometria / WL Default / iOS / Android от EMCD Web не отличаются — поломок нет.
- Нахлёст — числом: `gap` −4 / −6 / −8 (rawCount 6). Число аватаров в варианте фиксировано (4): правило «до 5» в наборе не представлено.
- Обводка задаёт видимый размер: при кольце не в цвет подложки круги выглядят больше номинала.
