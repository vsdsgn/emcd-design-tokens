## Дефекты (править в Figma)
- [листы 01–12 · все 24 ячейки, также «Текст · …», «Текст 200 %», «Свойство · Show message = Off» · экземпляры 1 и 5 (State=Default, Length 4 и 6)] в пустых ячейках и в ячейке с фокусом показана цифра «4» цветом плейсхолдера (ряд читается «4 8 4| 4» и «4 8 4| 4 4 4») → ждали плейсхолдер «0» (описание Code cell: Empty — плейсхолдер 0). Причина — во вложенном Code cell: свойство Digit привязано к Empty и Focus (см. review/Code_cell.md); править там, Code input подтянется.
- [лист 12 · «Текст · long» · экземпляр 1; лист 13 · «Текст 200 % · все варианты» · все 8 экземпляров] сообщение, перенесённое на вторую строку, выровнено по левому краю, а ряд ячеек стоит по центру (в 200 %: ряд сдвинут вправо, «0:45» прижато влево) → ждали выравнивание текста по центру, как у однострочного сообщения (в ячейках L0–L3 и в языках оно стоит по центру ряда). У слоя `message` — text-align Left при ширине Fill.
## Заметки (не дефект / на решение)
- [листы 01–12 · все ячейки · экземпляры 2, 3, 4, 6, 7, 8] в Error, Success и Disabled под рядом тот же текст по умолчанию «Отправить код повторно через 0:45» (красным / зелёным / серым): свойство Message одно на набор, цвет меняется верно (`text/danger` / `text/success` / `text/disabled`), но пример текста противоречит состоянию. На решение: оставить (текст задаёт продукт) или дать образцы на борде.
- [листы 01, 04–06, 07, 10–12 · «… · iOS · L0», «… · Android · L0» · экземпляры 1–4] Length=4 на iOS / Android собран из ячеек L (64 × 68), как на Web. Правило описания: «Web 4 цифры — L, остальное — M». Оси Size у набора нет, от режима Platform размер ячейки не зависит. На решение: привязать размер ячейки к Platform, либо добавить ось, либо поправить правило.
- [лист 13 · «Текст 200 % · все варианты» · экземпляры 1 и 5 (Default)] в ячейке с фокусом каретка наложена на увеличенную цифру-плейсхолдер (позиция каретки фиксирована). Уйдёт вместе с правкой плейсхолдера в Code cell (в Focus цифры быть не должно). Ячейки при 200 % не растут, цифры помещаются, обрезки нет; сообщение переносится на две строки, высота растёт, наложений нет.
- ? [листы 07–12 · Dark · все бренды · L0 · экземпляры 1 и 5] пустые ячейки (рамка `control/border/default` и плейсхолдер) в Dark на L0 почти сливаются с фоном; на L1–L3 ячейка темнее подложки и читается. То же в заметках Code cell.
- ? [листы 07–12 · Dark · экземпляры 3 и 7 (Success)] рамка `status/success/solid` в Dark заметно темнее текста сообщения `text/success` и рамки Error; различима, но слабее, чем в Light.
- [лист 12 · «Текст · long»] длинное сообщение переносится на 2 строки (ширина ячейки стенда 360), не усекается; ряд ячеек не ломается. В описании правила переноса сообщения нет — только «ширина не больше `size/code-input/max`».
- [лист 12 · «Текст · de / ar / hi / th / ja / kk»] сообщения в одну строку по центру, обрезки по высоте нет (ar, hi, th — целиком). Порядок ячеек в ar — слева направо, ожидаемо для цифр.
- [лист 13 · «Свойство · Show message = Off»] сообщение скрыто у всех 8 вариантов, высота сокращается до ряда ячеек, раскладка цела.
- Error / Success / Disabled различимы во всех темах и брендах; Disabled гасит и ячейки, и сообщение. Geometria — меньший радиус и свой шрифт, WL — свой шрифт; iOS / Android от Web не отличаются.
- Манифест: `maxw=400 RAW` — max-width числом, в описании назван токен `size/code-input/max`. Служебных слоёв у набора нет (кольцо, зона и поле — у Code cell). У борды нет секций 05 и 07.
- В описании две строки про движение («Движение:» и «Motion:») — дублируют встряску.
