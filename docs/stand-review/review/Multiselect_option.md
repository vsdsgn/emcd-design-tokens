## Заметки (не дефект / на решение)
- Порядок экземпляров на стенде: Default, Hover, Pressed, Disabled (в манифесте ось State перечислена Default, Hover, Disabled, Pressed) — порядок вариантов в наборе не совпадает с порядком значений оси; не дефект отрисовки.
- Hover и Pressed различимы на L0–L3 в Light и Dark; Disabled — погашенный текст без подложки. Geometria — радиус меньше; WL Default как EMCD; iOS / Android как Web.
- Стенд НЕ покрыл: Selected (галочка справа), слот Leading, Description, Focus ring, Show hit area, Safe margin — это свойства вложенного `_List row`, на уровне набора свойств нет (`props` пуст), ячеек «Свойство · …» нет. Галочка выбранного на стенде не видна ни в одной ячейке.
- ? «Текст · long»: подпись переносится на 4 строки, строка растёт по высоте, усечения нет; «Текст · de» — длинное слово рвётся посреди («…gesellschaf / ten»). В описании правило есть только для описания («в одну строку»), для подписи правила нет — на решение: перенос или усечение.
- «Текст · ar»: арабский текст прижат к левому краю (стенд не переключает направление) — зеркалирование не проверено. hi / th / ja / kk — без обрезки по высоте.
- «Текст 200 %»: строка растёт по высоте, текст не обрезан, ширина 280 сохраняется.
- Ширина корня 280 — числом (образец; в списке строка тянется по ширине родителя).
