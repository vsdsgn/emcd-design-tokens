- Web / iOS / Android одинаковы — размеры от платформы не зависят.
- «Текст · …» — только вариант по умолчанию (Off), текста нет; «Текст 200 %» — без изменений.
- Ширина выбранной точки 16 — числом (манифест: `(root):w=16`), токена нет.
