## Дефекты (править в Figma)
- [листы 01–02 · все 24 ячейки тем и «Текст 200 %» · экземпляры 1 и 4, 3 и 6] ось Color ничего не меняет: Primary Default (1) и Secondary Default (4) совпадают попиксельно (сверено по вырезкам Light · EMCD · Web · L0 и Dark · EMCD · Web · L0), оба в цвете основного текста; Disabled (3 и 6) тоже одинаковы → ждали у Secondary иконку во вторичном цвете (`icon/secondary` / `text/secondary`), как в legacy «icon color = secondary / primary». В манифесте у набора нет токенов цвета иконки (только корень и `skeleton`) — цвет, похоже, приходит из вложенной иконки и не переопределён.
