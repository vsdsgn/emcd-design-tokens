## Заметки (не дефект / на решение)
- Порядок: Default, Current, Success — 3 из 3. Default — серый круг с обводкой и подпись `text/secondary`; Current — круг `control/checked` (EMCD / WL фиолетовый, Geometria синий), подпись `text/primary`; Success — зелёный круг с галочкой, подпись `text/primary`. Подписи Current и Success одинаковые — различие только в символе.
- ? Success: галочка в Light тёмная (≈ #0D120D на #317B34, контраст ≈ 3.7:1), в Dark — белая. Для графики ≥ 3:1 проходит, но в контракте Step symbol содержимое Success записано как `text/on-accent` — проверить привязку цвета иконки в Light (вопрос к Step symbol).
- Light / Dark, L0–L3: круг Default читается на всех уровнях (темнеет / светлеет вместе с подложкой). iOS / Android = Web; WL = EMCD.
- ar, hi, th, ja, kk: подпись переносится на 2 строки (hi — в одну), обрезки по высоте нет; символ — по центру высоты. В ячейке ar символ остаётся слева — стенд не включает RTL-раскладку.
- «Текст 200 %»: подпись растёт, обрезки нет; круг 24 не растёт, цифра удвоенного кегля занимает почти всю высоту круга, но не обрезана.
- Show description = On: описание второй строкой (`text/tertiary`, Body/SM) у всех трёх вариантов, символ центрируется по высоте двух строк; раскладка не ломается. В Dark описание на стенде не показано (ячейка только Light).
- max-width 160 — числом (`maxw=160 RAW`); в описании — `size/step/max`: привязать.
- Служебных слоёв (Focus ring, hit area) нет: шаг неинтерактивен; если Stepper допускает переход по нажатию на пройденный шаг — зона и фокус нужны у обёртки (на решение).
