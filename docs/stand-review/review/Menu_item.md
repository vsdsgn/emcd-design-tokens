## Заметки (не дефект / на решение)
- 24 ячейки креста (листы 01–12): порядок 16 вариантов верный (Size M → L; внутри Tone Default → Danger; State Default / Hover / Pressed / Disabled). Высоты по пикселям: M 44, L 56 на Web / iOS / Android. Hover и Pressed различимы между собой и с подложкой на L0–L3 в Light и Dark (в Dark L3 Hover тонкий, но виден). Disabled погашен (иконка и подпись), подложки нет.
- Tone=Danger + State=Disabled выглядит так же, как Default + Disabled (серый, без красного) — ожидаемо для `*/disabled`; на решение не выносится.
- Danger в Dark светлее (коралловый) — цвет меняется по теме, читается на L0–L3.
- Geometria: радиус плашки меньше (≈2 против ≈4 по пикселям у EMCD / WL) на Web / iOS / Android, Light и Dark — отличие бренда, не поломка. WL Default — другая гарнитура подписи, раскладка та же.
- iOS / Android: у M иконка слота Leading крупнее, чем на Web (подпись сдвинута на 4 px) — режим Platform; у L одинаково. Поломок нет.
- «Текст · ar»: иконка слева, подпись прижата влево — стенд не переключает направление; зеркалирование слотов по стенду проверить нельзя. ar / hi / th / ja по высоте не обрезаны, в одну строку.
- «Текст 200 %» (лист 13): подпись переносится на 2 строки («Добавить / воркер»), строка растёт по высоте, обрезки и наложений нет; иконка Leading не растёт (остаётся 20 / 24) и рядом с удвоенным кеглем выглядит мелкой — на решение.
- Ячеек «Свойство · …» нет: у набора нет своих свойств (props пуст). Description, Trailing, Selected, Show selection, Focus ring, Show hit area, Safe margin — свойства вложенного `_List row`; на стенде не показаны, значит не просмотрены: глиф выбора, галочка Selected, кольцо фокуса, зоны, строка с описанием (в т. ч. L «с описанием и крупной иконкой»), шеврон подменю.
- На стенде во всех вариантах, включая L, только иконка «плюс» и одна подпись: назначение L (монета 32 + описание) не проиллюстрировано вариантом по умолчанию.
