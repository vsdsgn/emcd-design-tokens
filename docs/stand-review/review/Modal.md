## Заметки (не дефект / на решение)
- Крест: L1–L3 внутри модалки пиксель в пиксель равны L0 (обе темы) — поверхность оверлея от уровня не зависит, верно. Dark L3: модалка (#1A1A1A) темнее подложки L3 (#232323), край держит обводка `border/subtle` — на решение (модалка всегда над `surface/overlay`).
- iOS / Android отличаются от Web только крупным крестиком (режим Platform) — во всех брендах. Geometria: синий акцент, свой шрифт, меньший радиус кнопок; WL Default: шрифт Inter. Всё читается.
- Header=Coin: заголовок `type/heading/lg` (у Title — `type/display/md`), монета 32 + описание; Header description действует только на Coin (bound 4) — Off убирает строку «BTC · сеть Bitcoin», раскладка цела.
- Header=Empty: шапка — пустая строка высотой крестика. Show close = Off у Empty (лист 81, экз. 9–12) оставляет пустое поле ~60 px над Body → на решение: запретить сочетание или схлопывать шапку.
- Footer=None: Footer slot скрыт (bound 9 из 12), высота по Body — ок. Horizontal: отмена слева, главная справа — по описанию.
- Текст (лист 73): меняется только Title (подписи кнопок и Body — во вложенных / слоте, стенд их не трогает). Ширина модалки 560 больше ячейки 360 — правая часть (крестик, конец строки) срезана стендом, не проверена. Заголовок переносится (long — 4 строки), правила числа строк в описании нет; de — длинное слово рвётся посреди. ar, hi, th, ja, kk — без обрезки по высоте. RTL стенд не переключает.
- Header=Coin с длинным заголовком (парковка 13.11: «обрезается без многоточия») стендом не проверен — в текстовых ячейках только вариант по умолчанию.
- 200 % (листы 74–76): заголовок, описание и Body растут без обрезки. Подписи кнопок масштабируются через одну (Stacked: «Отмена» крупно, «Подтвердить» — нет; Horizontal — наоборот; Single — нет) — похоже на поведение стенда со слотом Footer, ? не дефект набора. Кнопки XL 56 вмещают подпись 200 %.
- Слоты Body и Footer slot — на стенде образец текста и кнопки, содержимое слотов не проверялось.
- Состояний у набора нет; Hover / Pressed / Focus — у вложенных Button и Icon button; служебных слоёв у корня нет (layers 0).
