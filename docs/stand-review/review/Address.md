## Заметки (не дефект / на решение)
- Default → Copied: иконка копирования меняется на галочку, под строкой появляется «Адрес скопирован» (`text/success`), читается в Light и Dark на L0–L3. Высота варианта Copied больше на строку статуса — при копировании раскладка под компонентом сдвинется на 2 с; на решение: резервировать место под статус или показывать его поверх (Toast / тултип).
- «Текст · ar»: подпись и адрес прижаты влево — стенд не переключает направление; изоляцию направления в RTL по стенду проверить нельзя.
- hi / th / ja / kk / de: по высоте не обрезано; de переносится на 2 строки по символам (моноширинный) — для адреса ожидаемо.
- «Текст 200 %»: подпись, адрес и статус растут, обрезки и наложений нет; иконки кнопок не растут (размер от `control/height/sm`).
- Geometria / WL Default / iOS / Android от EMCD Web не отличаются (кроме гарнитуры подписи в WL) — поломок нет.
- Кнопки `copy` / `show QR` / `copied` — фреймы с иконками, а не экземпляры Icon button (в манифесте nested только `(icons)`), служебных слоёв нет (ring 0, hit 0, safe 0); состояний Hover / Pressed / Focus у кнопок в наборе нет. По описанию «Копировать — Icon button».
- Ширина корня 360 — числом (rawCount 4). Булевых свойств нет: QR показан во всех вариантах, хотя по правилу «QR — только для адресов пополнения» — нужен переключатель (например, Show QR).
