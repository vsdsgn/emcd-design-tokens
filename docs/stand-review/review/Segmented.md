## Заметки (не дефект / на решение)
- Light / Dark, L0–L3, EMCD / Geometria / WL: дорожка `control/segment-track` и подложка выбранного сегмента различимы на всех уровнях; выбранный — первый сегмент, подпись основным цветом, остальные — вторичным. На L0 в Light дорожка светлая, но видна; по описанию ставится на L1 и L2.
- Высоты S / M / L / XL различаются ступенями, сегменты равной ширины, порядок вариантов: Items=2 и 3 по размерам, затем Items=4.
- «Текст · hi» помещается без наложения. ar не зеркалится (стенд не переключает направление).
- Items=4: третий и четвёртый сегменты по умолчанию с одинаковой подписью «Месяц» — заменить на осмысленный пример («Год»).
- Items=4 при Size=S (ширина 240): подписи стоят вплотную уже при 100 % — запас на перевод минимален.
- Ширина корня 240 / 280 / 320 / 360 — числом (4 значения, rawCount 12). Своих свойств и оси State у набора нет: Disabled всей группы, Hover / Pressed / Focus — только через вложенные Segment; служебные слои — у Segment (у набора ring 0, hit 0).
- iOS / Android от Web не отличаются; Geometria — меньшие радиусы; WL — гарнитура. Поломок нет.
