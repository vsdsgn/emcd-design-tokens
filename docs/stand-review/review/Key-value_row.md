- [лист 05 · «Текст · kk» · экземпляр 1] название перенесено на 4 строки («Сыртқы / әмиянға / қаражат / шығару») рядом со значением в одну строку → ждали не больше двух строк (правило описания).
- [лист 05 · «Текст 200 %» · экземпляры 1 и 3 (Default, Muted)] название «Комиссия сети» разбито на 3 строки с разрывом внутри слова («Комис / сия / сети»); у экземпляра 2 (Total) — 2 строки, тоже с разрывом слова → ждали не больше двух строк и перенос по словам; причина та же: значение не уступает ширину, `key` сжимается без нижнего предела. Обрезки по высоте нет.

## Заметки (не дефект / на решение)
- Порядок: Default, Total, Muted — 3 из 3. Total — линия сверху (`border/subtle`), название и значение Medium, отступ сверху больше; Muted — значение `text/secondary`. Название у Default и Muted одинаковое (`text/secondary`) — отличие только в цвете значения.
- Light / Dark, L0–L3: текст читается везде; линия Total (`border/subtle`) видна на всех уровнях, в Dark · L0 слабая, но различима. Geometria / WL отличаются только шрифтом; iOS / Android = Web.
- ar, hi, th, ja: название переносится на 2 строки или помещается, значение в одну строку, обрезки по высоте нет. В ячейке ar порядок не зеркалится (название слева, значение справа) — стенд не включает RTL-раскладку; в коде порядок зеркалит контейнер.
- Ширина корня 360 — числом (`(root):w=360`): в экземпляре строка должна тянуться по ширине родителя (Fill).
- Служебных слоёв и булевых свойств нет (неинтерактивная строка) — ячеек «Свойство» нет.
- В описании нет строки Legacy; источник назван — «.sum list group» в Web App (88 вхождений).
