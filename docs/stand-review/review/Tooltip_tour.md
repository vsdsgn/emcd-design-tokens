## Заметки (не дефект / на решение)
- Порядок вариантов: Top / Neutral, Top / Accent, Bottom / Neutral, Bottom / Accent. Top — стрелка снизу, Bottom — сверху; по брендам и темам цвета меняются верно (EMCD / WL — фиолетовый, Geometria — синий), Dark Neutral отделяется обводкой `border/default`.
- Accent: «Далее» — инверсная кнопка (Light чёрная, Dark белая), «Пропустить» — белый текст; читается во всех брендах.
- Show skip = Off противоречит правилу описания «“Пропустить” всегда доступен» — либо убрать свойство, либо записать, когда выключать (например, последний шаг не нужен — там «Готово»).
- Длинный текст (лист 12): шаг, заголовок и описание переносятся без лимита строк, подсказка растёт до 4+4+4 строк; ширина держится 320. Правила усечения в описании нет — на решение.
- de: длинное слово в заголовке разбито без дефиса — перенос Figma.
- ar / hi / th / ja / kk: обрезки по высоте нет; в ar стенд не зеркалит раскладку.
- Шаг «Шаг 1 из 4» — прозрачность 0.72 числом (временное исключение в `docs/exceptions.md` до 2026-12-13).
- ? Dark: `surface/raised` темнее фона L2 / L3 (лист 09) — вопрос Foundations, подсказка отделена обводкой и тенью.
- Платформы: iOS / Android не отличаются от Web — размеры от платформы не зависят.
