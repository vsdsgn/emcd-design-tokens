- Языки ar, hi, th, ja, kk: по высоте не обрезаны, помещаются без усечения. Арабский: точка слева, текст справа от неё (стенд LTR) — зеркалирование делает таблица.
- [лист 02 · «Текст 200 %»] подпись удвоенного кегля растёт, не обрезана и не наезжает на соседей; точка не растёт (экземпляры 1, 3).

На стенде подложки бейджа нет ни в одном варианте — все три выглядят как точка + подпись. - Своих свойств нет: подпись и тон — у вложенного Status; на стенде только тон Success. Булевых свойств нет.
