## Заметки (не дефект / на решение)
- Описание: промо-карточка указана в слоте Footer, на стенде она между логотипом и Nav (в Header или отдельным слоем `promo`) — свести описание и сборку.
- Light · L1 (лист 02) и Dark · L1 (лист 08): поверхность сайдбара равна подложке (245 = 245; 26 = 26), держится обводкой `edge/hairline`. Dark · L2 / L3 (лист 09): сайдбар темнее подложки — по описанию он плавает на `bg/base` (L0), на L1–L3 не ставится; записать как правило.
- Логотип в Header — текстовый плейсхолдер: на длинном тексте и языках режется краем без многоточия (листы 13–15). В реальном использовании — картинка логотипа; WL Default (листы 05, 06, 11, 12) показывает «EMCD» — бренд подставляет свой логотип в слот.
- Языки (листы 13–15): пункты Nav — одна строка с многоточием, по высоте de, ar, hi, th, ja, kk не обрезаны; текст промо переносится, карточка растёт. ar не зеркалится (стенд не переключает направление); Counter с текстом вместо числа — артефакт подстановки образца.
- 200 % (лист 16): Collapsed=On — «E» и Counter «12» крупнее, Counter наезжает на иконку сильнее обычного; не обрезано.
- «Свойство · Promo = Off» (лист 17): промо скрывается, Nav поднимается под логотип; у Collapsed=On промо нет в обоих значениях — ожидаемо (свойство привязано к 1 варианту).
- Платформы: Sidebar только для Web (Expanded+). iOS / Android на стенде — иконки пунктов крупнее (режим Platform), раскладка не ломается; для набора неприменимо.
- Бренды: Geometria — синий акцент и меньшие радиусы, WL — свой шрифт; Dark — цвета меняются корректно.
- Expressive (`material/regular`, свечение у активного) на стенде не показан — проверена только Base (непрозрачная поверхность).
- Ширины 240 / 72 и высота 800 — числом (raw).
