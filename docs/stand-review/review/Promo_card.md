## Заметки (не дефект / на решение)
- Действие в S и M — разного вида: S — текстовая кнопка «Подробнее» без подложки, M — кнопка с подложкой «Получить каталог». Правила выбора вида действия в описании нет; на решение — один вид или записать правило по Size.
- Accent: `accent/subtle` меняется по бренду (EMCD / WL — фиолетовый, Geometria — синий) и теме; текст и действие читаются в Light и Dark на L0–L3. Кнопка M на Accent в Dark — подложка кнопки слабо отличается от карточки, текст читается.
- «Свойство · Show description = Off» / «Show action = Off»: слой скрывается, карточка сжимается по высоте, раскладка не ломается. «Show media = On»: появляется плейсхолдер `media` (S ≈ 56, M ≈ 88 по стенду, справа сверху), текст его не перекрывает; на Accent плейсхолдер серый (`surface/level-2`).
- «Текст · long»: заголовок и описание переносятся без ограничения строк (9 + 7 строк), карточка растёт по высоте; усечения нет — на решение: ограничить число строк (например, 2 + 3).
- «Текст · de»: длинное слово рвётся посимвольно («Rechtsschutzver / sicherungsgesell / schaften») — следствие узкой колонки. ar, hi, th, ja, kk по высоте не обрезаны; ar не зеркалится (стенд не переключает направление).
- «Текст 200 %»: карточка растёт по высоте, текст не обрезан; подпись кнопки M занимает всю высоту кнопки (32) впритык, не обрезана — высота кнопки не растёт.
- По правилу «закрывается пользователем», но крестика и свойства для него в наборе нет.
- Состояний (Hover / Pressed / Focus) у карточки нет; служебных слоёв нет (ring 0, hit 0). Ширина корня 222 / 343 и отступ 96 — числом.
- iOS / Android / WL от EMCD Web не отличаются (WL — гарнитура); Geometria — меньшие радиусы; поломок нет.
