## Заметки (не дефект / на решение)
- Порядок вариантов в наборе: Icon Default / Hover / Pressed → Extended Default / Hover / Pressed → Icon Disabled → Extended Disabled (Disabled обоих Layout стоят в конце, а не внутри своей группы). Ничего не ломает; при желании выровнять порядок по осям.
- [лист 03 · «Текст · long | de | ar | hi | th | ja | kk»] вариант по умолчанию — Layout=Icon, текста в нём нет: длинная подпись и языки у Extended стендом НЕ проверены (правило «до 20 знаков» и поведение при превышении не видны). Нужна ручная проверка Extended с длинной подписью.
- 200 % (лист 03): подпись Extended растёт, кнопка расширяется, высота 56 сохраняется, обрезки и наложений нет; иконка не масштабируется.
- Hover / Pressed различимы: в Light слой осветляет (Hover слабее, Pressed сильнее), в Dark — затемняет; Disabled — серый, без тени, подпись и иконка погашены. Geometria — синий, EMCD / WL — фиолетовый.
- ? Light L3 (лист 01): Disabled-подложка близка к поверхности (серый на сером), контур читается слабо, но виден; в Dark L0 — аналогично. Для Disabled допустимо.
- Тень в Dark практически не видна (ожидаемо для Elevation на тёмном).
- Служебные слои: Show hit area — красная зона по габариту кнопки (8 из 8); Safe margin — зелёная рамка вокруг каждой кнопки (8 из 8); Focus ring — кольцо с зазором, повторяет скругление (8 из 8, включая Disabled).
- iOS / Android: иконка и подпись крупнее, кнопка Extended шире — раскладка цела. В манифесте ширина `hit area · web` у Extended — числом 183 (при другой длине подписи зона не подстроится — проверить привязку к ширине).
- Описание: «на Web не используется», при этом стенд показывает ячейки Web — это режим Platform, не дефект. Состояния Focus на оси нет — фокус свойством Focus ring.
