## Дефекты (править в Figma)
- [лист 03 · «Текст · long» и «Текст · de» · экземпляр 1] `primary` и `secondary` не усекаются: строка уходит за корень (ширина 184) и режется только краем ячейки стенда (360) посреди буквы, многоточия нет → по описанию «длинный текст — многоточие»: текст по ширине корня, одна строка, усечение «…».
- [лист 04 · «Текст 200 % · все варианты» · экземпляры 1, 3, 4, 6] текст удвоенного кегля не помещается в корень 184 × 80 и выходит за него: Start Disabled (3) наезжает на End Default (4) — «userTableGuide» наложены друг на друга; у End Disabled (6) начало строки уходит влево за край ячейки («erTableGuide»); Start Default (1) заходит на Skeleton (2). Две строки (≈ 96) выше корня 80 → ждали усечение многоточием по ширине и рост высоты (или явное правило, что высоту задаёт Table row).
## Заметки (не дефект / на решение)
- Темы, бренды, платформы, L0–L3 (листы 01–03, 24 ячейки): порядок Start Default / Skeleton / Disabled, End Default / Skeleton / Disabled; цвета меняются в Dark; Disabled погашен и отличим от Default; Skeleton виден на всех уровнях, включая L3 Light и Dark. iOS / Android = Web.
- Skeleton — одна полоса 64 по центру высоты, со стороны Align (Start — слева, End — справа), хотя у Default две строки. Не дефект, зафиксировано в контракте.
- Языки ar, hi, th, ja, kk (листы 03–04): по высоте не обрезаны, строки не наезжают. Арабский стоит у левого края (Align=Start, стенд LTR) — зеркалирование делает таблица.
- Show secondary = Off (лист 04): вторая строка скрыта, `primary` встаёт по центру высоты, высота корня не меняется; у Skeleton изменений нет (ожидаемо).
- В WL Default строка чуть шире (шрифт бренда), раскладка не ломается.
