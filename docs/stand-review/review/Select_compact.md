## Дефекты (править в Figma)
- [лист 02 · «Текст · long», «Текст · de», «Текст · ar», «Текст · th», «Текст · ja», «Текст · kk» · экземпляр 1] подложка корня обрезана по max-width 200, а содержимое шире: шеврон стоит за пределами подложки, на белом фоне (в ja текст не усечён вовсе, шеврон снаружи) → текст должен усекаться так, чтобы шеврон оставался внутри корня с отступом `space/8`.
- [лист 02 · «Текст · ar» · экземпляр 1] арабский текст выходит за правый край подложки, многоточие стоит слева вплотную к монете (налезает на неё) → текст внутри корня, зазор до монеты `space/6`.
- [листы 01–02 · все ячейки тем и брендов · экземпляр 4 (Disabled)] шеврон не погашен: тот же цвет, что у Default (в Light замер 10,10,10 у обоих; в Dark — белый), при этом монета и текст погашены → шеврон цветом `text/disabled` (или `icon/disabled`).
## Заметки (не дефект / на решение)
- Порядок вариантов: Default, Hover, Open, Disabled, Pressed — Pressed стоит после Disabled; в описании Figma State перечислен без Pressed (Default / Hover / Open / Disabled). Дописать описание, порядок — на решение.
- Hover, Open и Pressed различаются только тоном подложки (Light: 221 / 214 / 211 при Default 235; Dark: 42 / 49 / 52 при 29); Open дополнительно отличается шевроном вверх. Open и Pressed по подложке почти одинаковы — допустимо.
- Disabled: подложка такая же, как у Default (235 / 29), гасится только содержимое — по токену `action/disabled`, на решение.
- «Свойство · Focus ring = On»: кольцо видно у всех 5, включая Disabled (служебный показ; в продукте Disabled фокус не получает).
- «Свойство · Show hit area = On»: красная зона совпадает с корнем (114 × 36) — зона Web; «Safe margin = On» — зелёное поле вокруг каждого, выглядит верно.
- 200 %: высота остаётся 36, текст по высоте не обрезан, ширина растёт.
- hi помещается целиком (короткая фраза), шеврон внутри.
- iOS / Android от Web не отличаются, Geometria — меньший радиус, WL — чуть шире (шрифт). L1–L3 в Light и Dark: Default на L1 / L2 читается, контраст подложки с фоном низкий, но граница видна.
- В манифесте высота 36 и max-width 200 — числом (в описании `size/row/compact` и `size/select-compact/max`).
