## Заметки (не дефект / на решение)
- Темы, бренды, платформы, L0–L3 (24 ячейки): порядок Default / Skeleton / Disabled; три иконки-кнопки (карандаш, копия, корзина) меняют цвет в Dark, читаются на L0–L3; Skeleton — одна полоса на всю ширину трёх кнопок; Disabled погашен. iOS / Android = Web, бренды не отличаются (Ghost без подложки).
- ? Dark · L0 · экземпляр 3 (Disabled): погашенные иконки едва видны на L0 — для Disabled допустимо, на грани.
- Свойства (лист 02): Button 2 = Off убирает среднюю кнопку, Button 3 = Off — третью; оставшиеся сдвигаются без дыр; Skeleton не меняется (свойства привязаны в 2 вариантах из 3 — ожидаемо).
- Текстовых свойств нет: «Текст · …» и «Текст 200 %» совпадают с вариантом по умолчанию.
- На решение: по описанию кнопки — Icon button Ghost S, но в манифесте вложенных экземпляров Icon button нет (`nested` — только иконки; `button 1…3` — собственные слои на `control/height/sm`, `radius/control-sm`). Hover / Pressed / Focus кнопок на стенде не видны, служебных слоёв (focus ring, hit area) у набора нет. Заменить слои экземплярами Icon button — тогда состояния и зоны придут из него.
- Иконки кнопок своих свойств замены в наборе не имеют (в `props` только Button 2 / Button 3) — меняются у вложенных иконок.
