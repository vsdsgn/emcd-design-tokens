## Дефекты (править в Figma)
- [листы 01–04 · все 24 ячейки · экземпляр 5 (State=Disabled)] иконка календаря не погашена: цвет тот же, что в Default (Light L0: иконка #676767 на #EBEBEB при тексте значения #8D8D8D; Dark L0: иконка #9C9C9C при тексте #777777) — иконка выглядит ярче значения → ждали `icon/disabled` у вложенного Input addon / Icon (Disabled у вложенных должен быть погашен).
- [лист 05 · «Текст · long» · экземпляр 1] подпись на рамке (Label) не усекается: строка идёт за правый край поля (320) и срезается краем ячейки (360), вырез рамки под подписью — на всю ширину поля → ждали усечение многоточием в пределах поля (как у значения / плейсхолдера, которое усечено верно). В «Текст · de» подпись заняла почти всю ширину рамки (до правого скругления), но ещё помещается.
- [лист 05 · «Текст 200 % · все варианты» · экземпляры 1–5] подпись на рамке при удвоенном кегле налезает на значение / плейсхолдер (строки «Период» и «ДД.ММ.ГГ → …» / «08.12.25 → 12.12.25» перекрываются), высота поля не растёт → ждали рост поля или смещение подписи без наложения. Наследуется от Input (Label position=On border) — править в базе.
## Заметки (не дефект / на решение)
- Состояния Default / Focus / Filled / Error / Disabled различимы во всех 24 ячейках: Focus — тёмная рамка и каретка, Error — красная рамка и красное сообщение вместо подсказки, Disabled — серая заливка. Dark, Geometria, WL, L0–L3 — цвета меняются, поле читается на всех поверхностях.
- iOS / Android: иконка календаря крупнее (режим Platform), раскладка цела.
- Geometria / WL: стрелка между датами рисуется глифом шрифта бренда — форма разная, читается везде.
- «Текст · long»: плейсхолдер усечён многоточием, подсказка переносится на 3 строки — корректно. 200 %: плейсхолдер усечён многоточием по ширине, подсказка / ошибка переносятся на 2 строки — не дефект.
- «Текст · ar»: текст не обрезан по высоте, но раскладка не зеркалится (подпись и значение слева, иконка справа) — стенд не переключает направление; зеркалирование и направленная стрелка в RTL на стенде не проверены. hi, th, ja, kk — без обрезки.
- Языковые ячейки заменяют плейсхолдер произвольным текстом; формат даты по локали стендом не проверяется.
- В манифесте у набора нет своих свойств (`props: []`): Label, подсказка и значение меняются только через вложенный Input. Ширина корня 320 — числом (`(root):w=320`).
- Hover в наборе нет (оси State: Default, Focus, Filled, Error, Disabled).
