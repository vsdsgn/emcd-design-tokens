## Заметки (не дефект / на решение)
- Все 24 ячейки: пункты-ссылки серые, текущая страница — `text/primary` и плотнее, разделитель «/» виден на L0–L3 в Light и Dark; Items 2 / 3 / 4 — порядок и высота одинаковые. Geometria и WL Default — другая гарнитура, раскладка цела.
- «Текст · long / de / kk»: первый пункт усекается многоточием (ширина пункта на стенде ≈ 200) — по правилу. Строка целиком не сжимается: второй пункт уходит за ширину ячейки 360, текущей страницы не видно — в узком контейнере схлопывание средних пунктов должен делать код.
- «Текст · …»: разделитель — текстовый слой, стенд подменил и его (вместо «/» — серый повтор текста). Не дефект компонента, но разделитель можно случайно переписать в экземпляре; на решение — заменить на вектор / иконку или запереть слой.
- ar / hi / th / ja: по высоте не обрезано. ar: порядок пунктов остаётся слева направо — стенд направление не переключает, зеркалирование проверить нельзя.
- «Текст 200 %»: все три варианта растут, обрезки и наложений нет.
- Ячейки iOS / Android не отличаются от Web; по правилу компонент только для Web.
- Варианта со схлопнутыми средними пунктами («…» с меню, больше 4) в наборе нет: ось Items — 2 / 3 / 4.
