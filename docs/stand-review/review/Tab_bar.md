## Заметки (не дефект / на решение)
- Длинный текст и языки (лист 02): подписи — одна строка с многоточием по ширине пункта 72 (правило Tab bar item); de, ar, hi, th, ja, kk по высоте не обрезаны. Подписи соседних пунктов стоят вплотную («Очень дли…Очень дли…») — внутреннего отступа у `label` нет; на решение — поле 2–4 по краям.
- 200 %: подписи 2× помещаются по высоте впритык (низ текста в 2 px от края), высота таббара не растёт; усечение по ширине — по правилу.
- Base: поверхность `surface/level-1`-подобная (245 / 26 по пикселям), не `surface/raised`, как сказано в A11y («при reduced transparency — `surface/raised`»); на L1 сливается с подложкой (держит линия сверху), в Dark на L2 / L3 темнее подложки. Таббар стоит на L0 у низа экрана — правило, не дефект; свести описание.
- Описание: в первой строке «Стекло (`surface/glass` + Glass/MD)», ниже и в привязке — `material/thin/fill` + `material/thin/blur` + `edge/hairline`; старые имена убрать.
- Expressive (`material/thin`, стекло) на стенде не показан — проверена только Base.
- Бренды: акцент выбранного пункта меняется (EMCD / WL — фиолетовый, Geometria — синий), Dark — корректно; Badge dot виден везде.
- Платформы: набор только для Compact (App + мобильный веб); Web-ячейки стенда = мобильный веб.
- Ширина корня 375 — числом (raw); в продукте — на всю ширину экрана (Fill).
