## Заметки (не дефект / на решение)
- Все 24 ячейки: Unread — фон `accent/subtle` + точка справа сверху, Read — без фона и точки; оба варианта одной высоты. Geometria — фон и точка синие, радиус меньше; WL Default — другая гарнитура, адрес переносится иначе («•••» уходит на вторую строку), раскладка цела.
- Кружок под иконкой (`surface/raised`) у Read сливается с подложкой в Light · L0 и Dark · L1 (цвета совпадают), на остальных уровнях виден. Иконка читается везде; на решение — нужен ли кружок у Read вообще.
- «Текст · long»: заголовок — 2 строки с многоточием, текст — 3 строки с многоточием — по правилу. Время — одна строка, длинное значение обрезается по краю блока без многоточия (стенд подставил длинный текст и во время; в продукте время короткое).
- «Текст · …»: карточка шире ячейки 360 (ширина 400), правый край и точка «непрочитано» обрезаны ячейкой стенда — не дефект компонента. de: длинное слово в заголовке и тексте переносится по словам, за карточку не выходит.
- ar / hi / th / ja / kk: по высоте не обрезано. ar выровнен влево, иконка слева — стенд направление не переключает, зеркалирование проверить нельзя.
- «Текст 200 %»: оба варианта растут по высоте, текст переносится, обрезки и наложений нет; иконка и точка остаются своего размера.
- Вся строка нажимается (по описанию), но в наборе нет Hover / Pressed, кольца фокуса и слоёв зоны нажатия (в манифесте служебных слоёв 0); булевых свойств нет.
- В описании ширина `size/toast/min … size/toast/max`; в манифесте привязан только max (400).
- Иконка в наборе одна (колокольчик), свойства замены иконки нет.
