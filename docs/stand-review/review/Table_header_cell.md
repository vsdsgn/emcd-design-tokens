## Заметки (не дефект / на решение)
- Описание: «текст Label/SM», а в манифесте `label` на `type/label/lg/*` — привести описание или привязку к одному.
- Порядок экземпляров на стенде: Default (Start × None / Ascending / Descending, End × то же), Skeleton (Start, End), Hover ×6, Pressed ×6 — первым идёт Default, хотя в оси State первым стоит Skeleton; умолчание взято Start / None / Default.
- Light / Dark, EMCD / Geometria / WL, L0–L3, Web / iOS / Android — чисто: неактивная колонка `text/tertiary`, активная `text/primary` + стрелка; Hover и Pressed различимы на всех уровнях; скелетон виден в Dark.
- Платформы на стенде не отличаются (высота 44 числом и на Web, и на касании) — по описанию так и задумано.
- ar на стенде выровнен по левому краю — Figma не зеркалит; RTL — задача кода (Start / End логические).
- hi, th, ja, kk, ar по высоте не обрезаны; 200 % — ячейки растут, обрезки нет.
- Focus ring = On — рамка внутри ячейки (исключение из `docs/exceptions.md`); рисуется и у Skeleton, хотя скелетон не фокусируется — не критично.
- Show hit area = On — зона совпадает с ячейкой 160 × 44 (raw `hit area · web` w=160 / h=44 числом).
- Show filter / Show info — иконки ставятся корректно: фильтр перед подписью (у End — перед стрелкой), info после; у Skeleton свойств нет (bound 18 из 20) — верно.
