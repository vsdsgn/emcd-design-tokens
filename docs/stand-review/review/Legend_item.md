## Заметки (не дефект / на решение)
- Порядок: Default, Hover, Selected, Skeleton — 4 из 4. Default — подпись `text/secondary`, Hover — `text/primary`, Selected — `text/primary` + Medium; Hover и Selected отличаются только насыщенностью начертания — различимо, но слабо.
- Light / Dark, L0–L3: подпись и маркер читаются везде; Skeleton в Dark · L0 виден слабо, но различим. Geometria / WL отличаются только шрифтом (ширина подписи) — ожидаемо; iOS / Android = Web.
- Длинный текст: одна строка, усечение многоточием по max-width 160 (long, de, th, kk усечены; hi, ja помещаются). Обрезки по высоте у ar / hi / th нет.
- «Текст 200 %»: подпись растёт, обрезки нет; маркер 12 × 12 и плашка Skeleton не растут.
- Show value = On: значение моноширинным (`font/family/mono`, `text/primary`) у Default / Hover / Selected; у Skeleton ничего не меняется (свойство привязано к 3 вариантам из 4) — ожидаемо.
- Focus ring = On: кольцо у всех четырёх, включая Skeleton — у скелетона фокуса быть не должно, в макетах не включать (на решение: убрать слой из Skeleton).
- Show hit area: у экземпляров 1–3 зона 24 по высоте покрывает строку. Safe margin: поля соседних экземпляров на стенде сливаются (шаг стенда меньше поля) — не дефект набора.
- max-width 160 — числом (`maxw=160 RAW`); ширины `hit area · web` 68 / 69 / 64 и высота 24 — числом (rawCount 8).
- По описанию Skeleton — «график грузится»; маркер серии в Skeleton не показывается (Legend swatch вложен в 3 варианта из 4).
