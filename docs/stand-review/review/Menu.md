## Дефекты (править в Figma)
- [лист 07 · «Текст · long» и «Текст · de» · экземпляр 1] подпись группы («Воркеры» → длинный текст) срезана клипом посреди буквы без многоточия («…помещается і», «…Auszah») → ждали одну строку с многоточием (или перенос) по ширине меню.
- [описание набора vs манифест] описание: подпись группы — «Overline, text/tertiary»; в наборе — `type/label/sm`, `text/secondary` → привести описание и слой к одному (что верно — решить).
## Заметки (не дефект / на решение)
- Крест 24 ячейки (листы 01–06): порядок M → L верный; строки M 44, L 56 (по пикселям). Разделитель перед Danger-пунктом на месте, Danger читается в Light / Dark. Geometria, WL Default — шрифт и радиус меняются, всё читается. iOS / Android: иконки M крупнее (режим Platform), раскладка цела.
- Dark L3 (лист 05): подложка меню равна поверхности L3, граница держится обводкой и тенью — правило, не дефект. L0–L2 — меню различимо.
- Текст: пункты (Menu item) переносятся максимум на 2 строки с многоточием — по правилу Menu item; de — длинное слово рвётся посреди («…versicherungsge / sellschaften»), как у Menu item. ar, hi, th, ja, kk — без обрезки по высоте. ar не зеркалится (стенд не переключает направление).
- 200 % (лист 08): пункты растут по высоте, обрезки нет; «Переименов / ать» рвётся посреди слова — ширина корня 300 числом (`(root):w=300`, при min 160 / max 320), меню не растёт по тексту. На решение: ширина по содержимому / триггеру в пределах `size/menu/min` … `size/menu/max`.
- Search = On: поле поиска над группой, одинаковой высоты в M и L; раскладка цела.
- Правило «max-height ~ 8 пунктов, дальше скролл» в наборе не выражено (токена max-height нет) и на стенде не проверено (в меню 4 пункта).
- Состояний у набора нет: Hover / Pressed / Disabled / Focus — у вложенных Menu item; служебных слоёв у корня нет.
