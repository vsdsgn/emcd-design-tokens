## Заметки (не дефект / на решение)
- Light L0 (листы 01–06, 13–24): Card Default (`surface/raised` = #fff) на `bg/base` #fff не видна — плашки нет, только Hover. В Dark на L0 плашка видна. На решение: правило «Card — только на L1+ / на подложке», либо обводка `border/subtle` у Card на L0.
- Light Card Hover (#f0f0f0) почти сливается с подложкой L1 (#f5f5f5, лист 07–08) и L2 (#ececec, лист 09–10): край карточки при наведении теряется. Логика верная (raised + слой состояния), но на L1–L2 Hover у Card слабый; на решение вместе с правкой raised.
- Plain Hover: подложка состояния во всю ширину строки (без радиуса), разделитель остаётся с отступом 16 — выглядит согласованно на L0–L3 Light / Dark (слой наложения, а не сплошной цвет). Card Hover — сплошной `raised` + слой; на всех уровнях один и тот же цвет (#f0f0f0 / #272727).
- Высота различается по оси Content (Big value выше, Description only ниже) — по причине содержимого, не дефект. L и M различаются кеглем 16 / 14 и 14 / 12, как в описании.
- Длинный текст: Label и Description переносятся максимум на 2 строки и усекаются многоточием (long, kk); de — перенос внутри слова (длинный немецкий композит, ожидаемо). hi — в одну строку, ar / th / ja — по высоте не обрезаны. RTL (ar) — раскладка строки не зеркалится (Leading слева) — проверить в коде.
- 200 %: Label / Description / Trailing по высоте не обрезаны, строки растут; монета 36 не масштабируется — ок.
- Платформы Web / iOS / Android и бренды EMCD / Geometria / WL визуально одинаковы, кроме шрифта и радиуса Card (Geometria — меньше); поломок нет.
- Демо-текст Big value «USDC USDT» (значение — тикер, единица — второй тикер) не похож на сценарий «значение Heading + единица»; лучше «1 250.00 USDT».
- ? Description only — единственная строка цветом `text/secondary` (серый); если это «название без подписи», логичнее `text/primary`. Сверить с legacy Content Type.
- Pressed / Disabled и служебные слои (Focus ring, зоны) — во второй половине (варианты 33–64) и во вложенной базе `_List row`; строки «Свойства» на стенде нет — не дефект.
