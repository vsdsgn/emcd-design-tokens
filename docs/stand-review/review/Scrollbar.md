## Заметки (не дефект / на решение)
- 6 вариантов в порядке набора: Vertical Default / Hover / Dragging, Horizontal Default / Hover / Dragging. Default — тонкий ползунок 4 без дорожки, Hover / Dragging — 8 с дорожкой: соответствует описанию.
- Цвета меняются в Dark (ползунок светлый); бренд на цвет не влияет (нейтральные токены); в Geometria ползунок 8 — с прямыми углами (радиус бренда), ползунок 4 и дорожка — скруглены.
- Dark · L0: дорожка Hover / Dragging едва видна на чёрном (ползунок читается отлично); на Light · L3 дорожка видна.
- Текстовых и булевых свойств нет: ячейки «Текст · …» одинаковые, «200 %» не меняет ничего — ожидаемо.
- iOS / Android = Web; по описанию компонент только для Web (в App — системный скроллбар) — ячейки iOS / Android формальны.
- Манифест: размеры числом (корень 12 × 120, ползунок 4 / 8 × 48), хотя описание называет `size/track/sm`, `size/track/md`, `size/scrollbar` — привязки нет.
- Служебных слоёв нет (hit area не нужен: область 12 — сам корень).
