## Дефекты (править в Figma)
- [лист 01 · «Текст · long», «de», «ar», «hi», «th», «ja»; лист 02 · «Текст · kk» · экземпляр 1] длинное значение Page не расширяет плашку: текст по центру вылезает за корень в обе стороны и обрезается левым краем ячейки → по описанию «Ширина растёт с числом (минимум — высота контрола)». Похоже, ширина корня фиксирована (в манифесте `(root):w=32` / `w=40` числом), а не Hug с min-width. Проверить на «100», «1000».
## Заметки (не дефект / на решение)
- Состояния различимы во всех темах, брендах и на L0–L3: Default — без подложки, Hover — слой, Pressed — слой темнее, Selected — `accent/subtle` + `text/accent` (фиолетовый у EMCD / WL, синий у Geometria), Disabled — серый текст без подложки.
- Dark · L0: Hover и Pressed отличаются слабо, но различимы.
- Web / iOS / Android одинаковы — явной поломки нет.
- Языки: строка в Page — нереалистичный случай (в свойстве число или «…»); высота глифов ar / hi / th не обрезана.
- [лист 02 · «Текст 200 %»] цифра растёт, плашка остаётся 32 / 40, обрезки нет.
- [лист 02 · Focus ring = On] кольцо у всех 10 вариантов, с зазором, радиус по размеру. Show hit area = On — зона 32 / 40 (Web) у всех. Safe margin = On — рамка у всех; у соседних экземпляров рамки сливаются в полосу (зазор стенда меньше двух полей) — артефакт стенда.
- В описании нет варианта для «…» (сказано «не нажимается», но отдельного состояния / свойства в наборе нет) и нет строки Legacy.
