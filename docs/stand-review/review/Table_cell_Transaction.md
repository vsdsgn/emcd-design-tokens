## Заметки (не дефект / на решение)
- Темы, бренды, платформы, L0–L3 (листы 01–04, 24 ячейки): порядок Unexpected / Credit / Neutral / Neutral secondary × Default / Skeleton / Disabled; Unexpected — «−» и число красные, Credit — «+» и число зелёные, Neutral — число `text/primary`, Neutral secondary — число `text/secondary`; `unit` всегда вторичный; в Dark красный и зелёный светлеют, читаются на L0–L3. Disabled гасит всё, знак остаётся. Skeleton — полоса 64 у правого края. iOS / Android = Web.
- «Текст · long» и языки (листы 04–05): длинная строка в Value / Unit уходит влево за корень и ячейку стенда, виден только хвост `unit`, число и знак — за краем. Для суммы длинного текста не бывает (усечения по описанию нет); в продукте ширину колонки задают по самой длинной сумме.
- Языки: по высоте ar, hi, th не обрезаны.
- Neutral secondary Default и любой Disabled близки по тону (вторичный и погашенный серый), различимы.
- Булевых свойств нет.
