## Заметки (не дефект / на решение)
- Порядок вариантов: Size M → L → XL, внутри State Default, Hover, Open, Filled, Error, Disabled, Loading, Skeleton — совпадает с манифестом; высоты растут M < L < XL, внутри одного Size одинаковы.
- Default / Filled / Error / Disabled / Loading / Skeleton различимы во всех 24 ячейках; Dark, Geometria, WL — цвета меняются, поле читается на L0–L3. Geometria — меньший радиус и свой шрифт, раскладка цела.
- ? Hover — заливка фиксированного цвета (Light #F0F0F0, Dark #181818), не слой поверх поверхности: на Light L1 (фон #F5F5F5) и L2 (#ECECEC), Dark L1 (#1A1A1A) поле при наведении почти сливается с подложкой, отличие держит только рамка. На решение: Hover поля — слой `state/hover` или отдельный токен поверх `surface/current`.
- Skeleton: лейбл «Сеть» остаётся текстом, плашка поля — скелетон, helper скрыт. Совпадает с логикой «форма грузится», но стоит зафиксировать в описании, что лейбл в Skeleton виден.
- iOS / Android: шеврон и спиннер крупнее (режим Platform), раскладка цела.
- «Текст · long»: лейбл переносится (3 строки), значение — одна строка с многоточием, helper переносится — корректно. de: лейбл переносится, значение усечено многоточием.
- «Текст · ar»: без обрезки по высоте, но раскладка не зеркалится (шеврон справа) — стенд не переключает направление; RTL на стенде не проверен. hi, th, ja, kk — без обрезки.
- 200 %: поле по высоте не растёт, но текст помещается без обрезки; ошибка переносится на 2 строки; в Loading плейсхолдер усечён многоточием («Выберите се…») из-за спиннера — не дефект.
- Focus ring = On: кольцо появляется у всех 24 вариантов, в т. ч. Disabled и Skeleton, где фокуса быть не может — правило «не включать у Disabled / Skeleton» записать в описание.
- Свойств, кроме Focus ring, у набора нет: лейбл, helper, плейсхолдер, Show leading — через вложенный Input.
