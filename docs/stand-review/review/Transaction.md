- [лист 01, 02 · «Light · EMCD · Web / iOS / Android · L0», листы 04–06 · «Light · Geometria / WL Default · * · L0» · экземпляры 1–12] подложка иконки (`icon`, `surface/raised`) на L0 в Light совпадает с фоном — круга не видно, иконка висит без подложки; на L1–L3 (листы 02–03) — белый круг виден → ждали подложку, видимую на любой поверхности L0–L3 (токен подобрать; у Avatar фон круга — `action/secondary/default`).
- [лист 08 · «Dark · EMCD · Web · L1» · экземпляры 1–12] то же в Dark: на L1 подложка иконки сливается с фоном (на L0, L2, L3 видна) → ждали видимую подложку на всех уровнях.
- [лист 12 · «Текст · long / de / ar / hi / th / ja / kk» · экземпляр 1] блок `content` сжат до ≈ 120 px: заголовок усечён многоточием (норма), а строка даты обрезана жёстко, без многоточия, Status («точка + слово») вытеснен и не виден (в hi видна только точка) → ждали: дата усекается многоточием, Status виден всегда (статус обязателен по описанию); `content` не уже `size/row/content-min`.
- [лист 13 · «Текст 200 % · все варианты» · экземпляры 1, 7 (левая колонка) и др.] при удвоенном кегле корень фиксированной ширины 400 (сырое значение): сумма упирается в правый край и тикер «BTC» обрезан; заголовок усечён до «Вывод…», дата обрезана без многоточия («09:2»), Status не виден ни у одного экземпляра → ждали: ширина корня по родителю (Fill), Status и дата не теряются, сумма не обрезается (правило Amount).
## Заметки (не дефект / на решение)
- [лист 12 · «Текст · long» и языки] стенд подставляет длинный текст и в значение Amount — сумма не усекается и уходит за край ячейки; по правилу Amount это норма (сумма не усекается), реальные данные — число.
- [лист 12 · «Текст · ar»] заголовок на арабском выровнен по левому краю, иконка слева — зеркалирование на стенде не снималось. de, hi, th, ja, kk — без обрезки по высоте.
- [листы 01–12] Status Completed / Pending / Failed различимы точкой и словом во всех темах и брендах; знак суммы по правилу: Withdrawal «−» (U+2212), Deposit / Reward «+» зелёным, Failed — без знака, `text/primary`. Exchange — без знака во всех статусах; правило знака для обмена в описании не названо — дописать.
- Описание: «строка — кнопка», «нажимается целиком», но в наборе нет оси State (Hover / Pressed / Disabled), кольца фокуса и зон нажатия (служебных слоёв 0) → на решение: состояния и фокус у обёртки (строка списка) или добавить в набор.
- Высота 64 и ширина 400 — сырые числа (24 значения = 12 × 2); по правилу высота — `size/row/lg`. iOS / Android от Web не отличаются.
- Манифест: у борды нет секций 05, 07, 08. Legacy в описании не указан (ближайший legacy — DS Web `table / transaction` → Table cell / Transaction).
