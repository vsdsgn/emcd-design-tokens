## Дефекты (править в Figma)
- [листы 01–02 · все 24 ячейки тем / брендов / платформ / L0–L3 и «Текст 200 %» · экземпляры 4–6 (Status=On) против 1–3 (Status=Off)] варианты On и Off неотличимы: в обоих контурная звезда одного цвета (чёрная в Light, белая в Dark), Disabled — одинаково погашенный контур → по описанию «Status On — в избранном»: ждали залитую / акцентную звезду у On (legacy `star active`).
## Заметки (не дефект / на решение)
- Порядок экземпляров: Off Default / Skeleton / Disabled, On Default / Skeleton / Disabled. Skeleton — полоса 24, одинаковая у Off и On (ожидаемо). Звезда меняет цвет в Dark, читается на L0–L3; Disabled погашен. Бренды и платформы не отличаются (акцентного цвета в наборе не видно — следствие дефекта выше).
- Звезда прижата к началу корня 80 (отступ `space/8`), а не по центру — выравнивание задаёт колонка; на решение, если колонка избранного должна быть по центру.
- Состояний Hover / Pressed / Focus и служебных слоёв (focus ring, hit area) в наборе нет, хотя по описанию это кнопка с `aria-pressed`. На решение: добавить по модели контролов выбора или собрать на Icon button.
- Текстовых и булевых свойств нет: ячейки «Текст · …» совпадают с вариантом по умолчанию; при 200 % иконка не растёт (ожидаемо).
