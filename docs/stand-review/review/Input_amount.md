- Порядок экземпляров: Default (Filled False, True), Focus, Error, Disabled, Hover — 10 из 10, пустых нет. Error выше остальных на строку Message — по причине.
- Состояния различимы во всех 24 ячейках: Default — рамка #E0E0E0 1 px; Focus — тёмная рамка 1 px (#707070 / Dark #939393); Error — красная рамка 2 px (#C4302C / Dark #EF625E), Description и Message красные; Disabled — серая заливка (#EBEBEB / Dark #1D1D1D), тексты и «Макс» погашены; Hover — заливка #F0F0F0 / Dark #181818 (слой 6 %).
