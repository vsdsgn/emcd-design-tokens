- [листы 01–03 · все ячейки тем, брендов и платформ · экземпляр 1 (Default)] единица «TH/s» прижата к правому краю карточки, между числом «124.5» и единицей ~160 пустого места → единица рядом с числом через `space/6` (слой `value` должен быть по содержимому, а не растянут).
- [лист 03 · «Текст · long», «Текст · de», «Текст · kk» · экземпляр 1] длинная единица вытесняет число: Value сжато до «…», многоточие налезает на первую букву единицы; единица обрезана по правому краю без многоточия (long, de) → число не сжимается, усекается единица (многоточием).
- [лист 03 · «Текст · ar», «Текст · hi», «Текст · th», «Текст · ja» · экземпляр 1] Value усечено до 1–2 знаков с многоточием («外部…», «ถอน…»), единица показана целиком → приоритет у числа, а не у единицы.
- [лист 03 · «Текст · ar» · экземпляр 1] многоточие подписи дельты стоит вплотную к бейджу (налезает на его край) → зазор `space/6`.
- [листы 01–04 · все ячейки · экземпляр 2 (Skeleton)] высота Skeleton ~93 против ~118 у Default (при Show footer = On — 93 против ~226) → одна высота у вариантов State (правило «в ряду карточки одной высоты», без прыжка при Skeleton → Default).
## Заметки (не дефект / на решение)
- «Свойство · Ambient light = On»: видимых отличий нет — по описанию в Base пятно прозрачное; проверять в теме Expressive.
- «Свойство · Show footer = On»: появляется пустая область ~110 (слот без содержимого) — ожидаемо. Info / Delta = Off — раскладка цела; Skeleton на эти свойства не реагирует (привязаны только к Default).
- Light · L1 и Dark · L1: заливка карточки `surface/level-1` совпадает с подложкой, карточку держит только обводка `border/subtle` — на решение (карточка рассчитана на L0).
- Label переносится на 2 строки и дальше усекается многоточием; подпись дельты — одна строка с многоточием. Языки по высоте не обрезаны.
- 200 %: карточка растёт по высоте, обрезки нет; иконка Info и Skeleton размер не меняют.
- Платформы и WL отличаются только шрифтом / шириной текста; Geometria — меньший радиус.
- В Skeleton нет плашки под иконку Info и под единицу — допустимо.
- Ширина корня 280 — числом (min-width — `size/card/min`).
