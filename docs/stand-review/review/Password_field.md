## Дефекты (править в Figma)
- [лист 12 · «Текст · long» и «Текст · de» · экземпляр 1] кнопка «глаз» не привязана к полю: при подписи в 2–3 строки она остаётся на прежней высоте — в «long» висит справа от третьей строки подписи над полем, в «de» сидит на верхней рамке поля → ждали «глаз» внутри поля, по центру по вертикали, при любой высоте подписи (сейчас слой `show password` стоит поверх Input по фиксированным координатам, а не в слоте поля).
- [лист 13 · «Текст 200 % · все варианты» · экземпляры 1–4] та же причина: «глаз» стоит на верхней рамке поля (подпись выросла, кнопка осталась на месте) → ждали внутри поля.
- [лист 12 · «Текст · long» · экземпляр 1] строки требований не переносятся и не усекаются: текст уходит за ширину корня и режется краем ячейки («…в одну строку и») → ждали перенос на следующую строку в пределах ширины поля (в «de» строка помещается впритык к краю поля).
- [лист 13 · «Текст 200 % · все варианты» · экземпляры 1–3] требование «Заглавная и строчная буквы» шире корня 320 и налезает на иконку соседнего экземпляра (у экземпляра 4 выходит за правый край поля) → ждали перенос строки требования.
- ? [листы 01–12 · все 24 ячейки · экземпляр 2 (State=Typing)] введённые символы серые и мельче, чем в Valid / Error (выглядят как плейсхолдер из точек) → ждали значение основным цветом текста (`text/primary`), как в экземплярах 3 и 4; отличие Typing — только рамка фокуса и каретка.
## Заметки (не дефект / на решение)
- Состояния различимы в Light и Dark, на L0–L3, во всех брендах: Empty — плейсхолдер и четыре прочерка; Typing — тёмная рамка, каретка, 2 из 4 с галочкой и зелёным текстом; Valid — 4 из 4; Error — красная рамка, сообщение «Пароль не соответствует требованиям» между полем и списком. Выполнено / нет различается не только цветом (галочка / прочерк).
- В Error высота варианта больше на строку сообщения: список требований сдвигается вниз.
- «Текст 200 %»: высота поля не растёт (плейсхолдер 200 % помещается впритык, по высоте не обрезан), сообщение об ошибке переносится на 2 строки, иконки галочки / прочерка и «глаз» не растут. Рост высоты поля — вопрос к Input.
- «Текст · long» / «de»: подпись поля переносится на 2–3 строки, плейсхолдер усекается многоточием — нормально.
- «Текст · ar»: направление не переключается (подпись и требования прижаты влево, «глаз» справа) — зеркалирование по стенду проверить нельзя. ar, hi, th, ja, kk по высоте не обрезаны.
- iOS / Android: поле и шаг списка требований чуть выше, чем в Web, — из режима Platform; поломок нет. Geometria — меньший радиус поля; WL Default — другая гарнитура (точки значения крупнее); поломок нет.
- «Глаз» — фрейм `show password` с иконкой, а не экземпляр Icon button (в манифесте nested только Input и иконки), служебных слоёв нет (ring 0, hit 0, safe 0); по описанию — «Icon button Ghost». Варианта «пароль показан» (перечёркнутый глаз, открытый текст) в наборе нет.
- Свойств у набора нет: требования нельзя скрыть (по описанию вход — без требований), тексты требований и подпись меняются только во вложенных слоях.
- На оси State нет Hover и Disabled. Ширина корня 320 — числом.
