## Заметки (не дефект / на решение)
- Порядок экземпляров: Horizontal · Off · Solid; Horizontal · On · Solid; Vertical · Off · Solid; затем те же три для Dotted. 6 из 8 — как в описании.
- Ось Style (Solid | Dotted) есть в наборе, но в описании Figma нет правила, когда брать Dotted, — дописать правило (в записи контракта пометил в `todo`). На стенде Dotted выглядит как короткий штрих, не точки.
- Dark · L0: сплошная линия #1D1D1D на #0A0A0A — видна слабо (так задан `border/subtle`); на L1–L3 видна лучше. Если разделитель должен читаться на L0 в Dark — вопрос к токену, не к набору.
- «Текст · long | de | ar | hi | th | ja | kk»: вариант по умолчанию — без подписи (Label=Off), поэтому в ячейках только линия; длинный текст и языки в Label text стендом НЕ проверены.
- «Текст 200 %»: подпись «или» удвоенного кегля не обрезана, линии по центру подписи; ширина варианта остаётся 320.
- Geometria / WL Default / iOS / Android не отличаются от EMCD Web — ожидаемо.
- Булевых свойств нет, ячеек «Свойство» нет.
