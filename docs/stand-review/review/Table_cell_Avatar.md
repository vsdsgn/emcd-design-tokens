## Дефекты (править в Figma)
- [листы 01–03 · все 24 ячейки тем / брендов / платформ / L0–L3 · экземпляр 3 (Disabled)] значки достижений (звезда, щит) остаются в полном цвете (чёрные в Light, белые в Dark), глиф аватара тоже не погашен; гаснут только имя и подпись → ждали погашенные значки и аватар (`*/disabled`), как у остальных ячеек.
- [лист 03 · «Текст · long», «Текст · de» · экземпляр 1] имя и подпись не усекаются: уходят за корень (280) и режутся краем ячейки стенда без многоточия, значки достижений вытолкнуты за край и не видны → по описанию «имя — одна строка с многоточием», значки должны остаться видимыми после усечённого имени.
- [лист 04 · «Текст 200 % · все варианты» · экземпляры 1, 3] имя удвоенного кегля со значками выходит за корень (280): у Default наезжает на полосу Skeleton (экземпляр 2) → ждали усечение имени многоточием или рост корня. По высоте не обрезано; аватар и значки не растут (ожидаемо).
## Заметки (не дефект / на решение)
- Темы, бренды, платформы, L0–L3: порядок Default / Skeleton / Disabled; тексты и подложка аватара меняются в Dark, читаются на L0–L3; Geometria / WL отличаются только шрифтом. iOS / Android = Web.
- Свойства (лист 04): Achieves = Off убирает оба значка; Star achieve = Off — остаётся щит; Shield achieve = Off — остаётся звезда; раскладка не ломается. Skeleton от свойств не меняется (ожидаемо).
- Skeleton — одна полоса 120 без круга аватара. На решение: добавить круг 40, чтобы загрузка повторяла раскладку.
- В описании «Avatar L 40», но у набора Avatar 40 — это Size=M (L = 56); в манифесте вложенного экземпляра Avatar нет — `avatar` собран локально (заливка `action/secondary/default`, `radius/chip`). На решение: заменить на экземпляр Avatar M и поправить описание.
- В описании «значки … не больше трёх» и Legacy «text badge», в наборе два значка (Star achieve, Shield achieve), свойства для третьего / text badge нет.
- Языки ar, hi, th, ja, kk: по высоте не обрезаны, помещаются; в ar значки стоят справа от имени (стенд LTR).
