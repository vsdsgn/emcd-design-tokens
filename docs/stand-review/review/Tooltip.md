## Дефекты (править в Figma)
- [листы 01–48 · все 24 ячейки · экземпляры Tone=Neutral 1–4, 9–16] обводка пузыря не отрисовывается: на краю пузыря сразу фон (Light L0: 245 → 255, Dark L0: 10 → 26, тёмной линии нет), при этом уголок `_Tooltip arrow` обведён (линия ≈ 226 в Light, ≈ 54 в Dark) → уголок выглядит отдельной фигурой, пузырь в Light L0 (белый на белом) держится только на тени. Ждали: `border/default` по всему контуру пузыря и уголка, как в описании («Neutral — surface/raised + обводка border/default»). ? Причина: обводка корня (`s:border/default`) перекрыта слоем `overlay surface`.
- [листы 31–36 · «Dark · EMCD · Web · L1», «L2», «L3» · экземпляры Tone=Neutral 1–4, 9–16] заливка `surface/raised` (#1A1A1A) совпадает с L1 (#1A1A1A) — пузырь сливается с подложкой, виден только текст; на L2 (#202020) и L3 (#262626) пузырь темнее подложки — выглядит «утопленным», хотя лежит поверх всего. Ждали: тултип отделён от любого уровня L0–L3 (видимая обводка `border/default` из п. 1 закроет; иначе — более светлая поверхность для оверлеев в Dark).

## Заметки (не дефект / на решение)
- Placement Start / End при одной строке (высота 58 = `size/tooltip/min`): Arrow Start / End выглядят так же, как Center — грань 58 = 16 + 26 + 16, уголку некуда сдвигаться (экз. 13–16, 21–24). На 200 % (высокий пузырь) уголок честно уходит к началу / концу грани — логика верна.
- Текст · long: 4 строки — компонент не ограничивает число строк; «до 3 строк» — правило контента (больше — Popover), не механика. Ширина держится на 320.
- Языки de, ar, hi, th, ja, kk — не обрезаны, перенос по 320 (de — на 2 строки), арабский набран справа налево корректно.
- Текст 200 %: все 24 варианта переносятся на 3 строки по 320, высота растёт, обрезки и наложений нет.
- Булевых свойств нет — листов «Свойство · …» нет.
- iOS / Android не отличаются от Web — ожидаемо: компонент только для Web (в App — Sheet).
- Пересечение уголков соседних экземпляров (экз. 1–2, 5–6 и т. п.) — раскладка стенда (зазор 16 < 2 × 6 выступа), не дефект.
- Accent: в Dark тот же `action/primary/default`, что в Light, белый текст читается; в Geometria — синий бренда. Чисто.
