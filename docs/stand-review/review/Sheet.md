## Заметки (не дефект / на решение)
- Крест: Web — поля 24, iOS / Android — 16 (`modal/padding` по Platform), крестик на App крупнее — ок. Geometria — синий акцент и свой шрифт, WL Default — Inter; всё читается.
- Видимость края: обводки у `overlay surface` нет. Light L0 — белая шторка на белой подложке, край только тенью; Dark L3 — заливка шторки = L3 (#262626), тень в Dark не видна, край неразличим. В продукте шторка всегда над затемнением (`surface/overlay`), поэтому на решение, не дефект; вопрос уже в парковке OPEN-QUESTIONS (13.11).
- На стенде заливка — Base (`surface/raised`): Light #FFF, Dark #262626. Expressive (`material/thick` + блюр) стендом не проверялся.
- Грабер (`border/default`): Light #E0E0E0, Dark #404040 — заметен, декоративный.
- Текст (лист 04): заголовок переносится без ограничения строк (long — 5 строк), крестик по центру шапки; de — длинное слово рвётся посреди. ar, hi, th, ja, kk — без обрезки по высоте. RTL стенд не переключает. Ширина 375 помещается в ячейку целиком.
- 200 % (лист 05): заголовок — 2 строки, Body растёт, обрезки нет. Подпись «Открыть в обозревателе» не масштабирована, «Закрыть» — да (как у Modal, похоже на стенд со слотом Footer).
- Show grabber = Off — шапка поднимается, ок. Show close = Off — шапка ниже на ~8 px (высота строки заголовка вместо крестика), ок. Show footer = Off — кнопки убраны, низ по Body.
- Show header actions = On: пустой слот Header actions увеличивает шапку на ~60 px (заголовок и крестик по центру) — содержимое слота на стенде пустое, раскладку с иконками не проверить; не дефект.
- Safe area снизу (описание) в наборе не выражена: нижний отступ = `modal/padding`, слоя / токена `os/safe-area/bottom` нет (после удаления Type=Menu) → todo.
- Ширина корня 375 — числом; max — `size/sheet/max` 640. Высота «до ~90 % экрана, дальше скролл» — токена нет, стендом не проверить.
