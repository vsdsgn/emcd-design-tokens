## Дефекты (править в Figma)
- [описание набора] противоречие: «Форма как у legacy: L — иллюстрация 200» vs «Правила: L — иллюстрация 160». На стенде (все листы 01–12, экземпляры 1 и 4) иллюстрация L ≈ 200: круг часов 129 px при M 62 px — та же пропорция, что 200 : 96 → оставить одно число (и в слоте, и в описании).
- [лист 15 · «Текст 200 % · все варианты» · экземпляры 1, 4] ? вложенные Button в слоте Actions масштабируются вразнобой: Primary «Добавить воркер» остался 1×, Secondary «Как подключить» — 2×; в экземплярах 2, 5 Secondary 1× → ждали одинаковый рост текста кнопок. Возможно, артефакт стенда (содержимое слота); проверить привязку текста кнопок к стилю.
## Заметки (не дефект / на решение)
- Крест 24 ячейки: Light / Dark, EMCD / Geometria / WL, Web / iOS / Android, L0–L3 — цвета меняются по теме и бренду (Primary фиолетовая / синяя у Geometria), иллюстрация в Dark — тёмный вариант; заголовок, текст, кнопки читаются на L0–L3. iOS / Android от Web не отличаются — размеры от платформы не зависят.
- Экземпляр 4 (L · Horizontal, ширина 720) шире ячейки 594 — справа обрезан ячейкой (текст «…статис», кнопка), не дефект набора.
- Geometria и WL: в M и S текст переносится на 3 строки с висячим «минут.» — ширина корня фиксирована, не дефект.
- Ширина корня — числом у всех вариантов (`(root):w=560 / 320 / 280 / 720 / 520`), не по контейнеру. Из-за этого строка «Текст» (ячейки 360) не проверяется полностью: вариант L · Vertical 560 обрезан ячейкой. По видимой части: заголовок переносится (long — 3 строки, по центру), не усекается; de — длинное слово в заголовке в одну строку без переноса; ar, hi, th, ja, kk — без обрезки по высоте; ar не зеркалится (стенд не переключает направление).
- 200 % (лист 15): заголовок и текст растут, переносятся, обрезки по высоте нет; M · Vertical заголовок переносится на 2 строки.
- Свойства (листы 16–17): Show text = Off — текст пропадает, раскладка цела; Show illustration = Off — иллюстрация пропадает у L / M (у S её нет — bound 4 из 5), L · Horizontal становится одной колонкой; Show actions = Off — кнопки пропадают; Dashed background = On — пунктир `border/default`, `radius/container`, без сдвига раскладки; в Light пунктир бледный, но различим.
- Правило выбора Layout (Vertical / Horizontal) в описании не задано — только «legacy position». На решение.
- Порядок оси Layout в манифесте — Horizontal, Vertical, а первый (по умолчанию) вариант — L · Vertical. Не дефект, но порядок значений оси можно выровнять.
- Состояний у набора нет; служебных слоёв нет; интерактивны вложенные Button.
