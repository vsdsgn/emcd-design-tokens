# Правки по стенду (после снимка версии Стефана 13.11)

Каждая правка проверена отдельным чтением. Приём для усечения: текст по содержимому + `maxWidth` текстового слоя (Plugin API теперь принимает) — корень растёт до своего max, текст усекается многоточием; в фиксированных контейнерах — текст Fill, одна строка, многоточие.

## 2026-11-13 (ночь)
- **Select compact:** значение усекается (`text` maxWidth 122 = 200 − отступы 8 + 8 − зазор 16 − шеврон 16 − монета 24 − зазор 6), шеврон всегда внутри; Disabled — шеврон `icon/disabled`.
- **Select:** Open — без каретки, значение `text/primary`, шеврон `icon/chevron-up` (подмена экземпляра; поворот во вложенном экземпляре Figma не переопределяет); Disabled — шеврон `icon/disabled` (прежний оверрайд не сохранился: `findAll` по умолчанию пропускал невидимые дочерние слоты — нужен `skipInvisibleInstanceChildren = false`).
- **Disabled гасит вложенные:** Date range field (иконка, подсказка), Input amount (иконка info, валюта → Select compact Disabled), Multiselect (подсказка), Table cell / Avatar (значки, глиф).
- **Длинный текст:** Table cell / Text, Date time, Coin, Image, Avatar — блок `content` Fill, тексты Fill, одна строка, многоточие (End — выравнивание вправо); Accordion заголовок — 2 строки; Key-value row ключ — 2 строки, значение — 1 строка ≤ 200; Stat card — единица рядом с числом (число ≤ 180, единица ≤ 64); Step подпись и описание — 2 строки ≤ 120; Table header cell подпись — Fill, 1 строка; Snack заголовок — 1 строка; Segment подпись — Fill, по центру, 1 строка (в Segmented).
- **Описания:** Active → Current (Step, Step symbol, Step trail), → Selected (Legend item, Nav item); строка «Длинный текст:» у 13 наборов.
- **Группы и строки:** Checkbox group, Radio group (Horizontal) — `items` переносится (wrap, max `size/field/max`); `_List row` — подпись и описание до 2 строк, `hint` ≤ 160 в 1 строку (Menu item, List item, Multiselect option); Transaction — `meta` Fill, дата усекается, Status не вытесняется; Card — обводка вне раскладки (Border не меняет размер, 72 варианта); Pagination Compact — высота 32 / 40 (range по содержимому); Pagination item — ширина по содержимому, min = высоте (`control/height/*`), отступы `space/8` («1024» → 47).
- **Цвета:** Table cell / Star On — звезда `icon/accent` (контур и заливка); Table cell / Icon Secondary — `icon/secondary`; Nav item Selected — `icon/accent`; Transaction — плашка иконки `action/secondary/default`; Page dot Selected — `icon/accent`; Divider Dotted — `border/subtle`.
- **Skeleton той же высоты, что Default:** Accordion (L 65, M 49; отступы header как у Default), Stat card (118), Legend item (16) — полосы в строках высотой строки текста (`skeleton line`).
- **Accordion:** отступы header и Content слева / справа `space/12` — подпись и шеврон не прилипают к краю подсветки.
- **Мелкие:** Code cell Empty / Focus — цифра скрыта (без «4»); Date cell Disabled — зачёркнуто (отличие от Outside); Progress — подпись 1 строка, значение ≤ 200; Tooltip tour — распорка в footer («Далее» справа при Show skip = Off); Suggest — ряд кнопок скрывается вместе с Primary action; Radio card — радио у первой строки; Segmented Items=4 — День, Неделя, Месяц, Год.
- **Ещё:** Multiselect Chips Open / Error — плейсхолдер `text/tertiary`; Toast Informer Neutral — крестик `icon/inverse` (был белым на светлой плашке в Dark), заголовок Informer растёт по высоте (200 %), кнопки Card по центру ряда; Input amount — подпись ≤ 180 с многоточием; Circle timer — дорожка и дуга масштабируются вместе (constraints Scale); Password field — «глаз» в слоте Trailing вложенного Field (не съезжает), требования переносятся; Promo card — картинка в потоке (`body`: column + media), без резерва под картинку при Show media = Off, обводка вне раскладки (Neutral = Accent по высоте).
