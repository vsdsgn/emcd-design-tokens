## Системные дефекты шаблона

Число борд — оценка по отчётам (всего 98).

### Шапка
- «Имя в коде» без префикса `Ds`, код в 11 — тоже: все борды с шапкой (≈ 95). Примеры: Button, Icon button, Modal.
- Уровень (атом / молекула / организм) указан, в контрактах `Level: unknown`: ≈ 95. Примеры: Skeleton, Sheet, Coin.
- «Где используется: Web · App · мобильный веб» шаблонно, в том числе у Web-only и Compact-only: ≈ 10. Примеры: Breadcrumbs, Floating button, Sheet, Scrollbar.
- «Было в legacy: —» при известном legacy: ≈ 17. Примеры: Code cell, Menu item, Transaction.
- Цвет бейджа статуса не системен (beta синий или красный; draft красный, синий, фиолетовый): ≈ 15 замечено. Примеры: Input amount, Code cell, Dropdown panel.
- Бейдж расходится со статусом набора: Input 404:91 и Textarea 353:1004 (draft при beta), Tab bar 366:4725, Table cell (beta при draft Star).

### 01 Когда
- В таблице «Не X, если» колонка «Превью» заполнена «—»: все борды полного шаблона (≈ 20). Примеры: Tab, Chip, Icon button.
- Нет «Когда не использовать» / правил выбора из контракта: ≈ 25. Примеры: Amount, Select, Menu item.
- Пустые пункты «• —»: Table row, Chart card.

### 02 Анатомия
- Машинный дамп слоёв вместо анатомии (служебные `pad L/R 2×1`, «Frame», «Vector», текст-заглушка как имя слоя): ≈ 50. Примеры: Calendar, Dropdown panel, Chart plot.
- Карточки пронумерованы, а выносок на превью нет, либо выноски наложены или указывают в пустоту: ≈ 12. Примеры: Code cell, Skeleton, Icon button.
- Карточки анатомии описывают не части (размер, правило, legacy): Spinner, Code cell.

### 03 Свойства
- Нет значений по умолчанию у осей: почти все (≈ 90). Примеры: Tab, Coin, Avatar group.
- Нет служебных свойств (Focus ring, Show hit area, Safe margin): ≈ 20. Примеры: Icon button, Transaction, Select compact.
- Значения обрезаны посреди слова: Suggest, Toast, Radio card, Tooltip tour, Empty state.
- Свойства поданы как свойства набора, а они на вложенном слое (Field, `_List row`): Input, Textarea, Menu item.
- «Матрица Size» с бессмысленными осями («Размер 1 / Размер 2», «Форма 1 / Форма 2»): Tab, Skeleton.

### 04 Состояния
- Показана малая часть матрицы: ≈ 30. Примеры: Radio (2 строки из 64), Icon button (5 типов из 240), Checkbox (15 из 96), Button (36 из 176), Transaction (12 из 36).
- Выпали отдельные значения State: Step symbol 8 / 12, Floating button 6 / 8, Tab bar item 2 / 4, Date cell 8 / 10, Radio card 6 / 8, Pagination item 6 / 10, Notification 2 / 6, Breadcrumb item 3 / 5.
- Курсор-стрелка перекрывает подпись в Hover / Pressed: ≈ 8. Примеры: Button, Tab, Chip, Radio.
- Машинные подписи «Size=M, State=Default», рваные ряды, одинокие ячейки: ≈ 30 (весь лёгкий шаблон). Примеры: Amount, Segmented, Menu item.
- 04 дословно повторяет 02 или называется «Состояния» у компонента без состояний: ≈ 8. Примеры: Menu, Overlay, Coin, Modal.
- Focus показан колонкой State, хотя это служебный слой: Icon button, Pagination item.

### 05 Зоны
- Колонки «Web (24)» и «Касание (44)» одинаковы, зона касания не больше компонента: ≈ 6. Примеры: Tab, Chip, Toggle, Segment.
- Зоны не нарисованы или раздел не собран при наличии зон в контракте: ≈ 20. Примеры: Textarea, Floating button, Menu item.

### 06 На поверхностях
- «Где нельзя» — шаблонная фраза «Ограничений по уровням нет. Проверять обводку (Off) `control/border/default` на L2–L3 в тёмной»: ≈ 90. Стоит и у компонентов без обводки (Tab, Amount, Spinner, Skeleton), местами противоречит контракту (Promo card, Card, Radio card, Segmented, Radio, Select). Реальные проблемы уровней не отражены.
- Подпись строк склеена в один блок («Error / Default», «XS Default», «Network On Default»), «Default» там, где оси State нет: ≈ 35. Примеры: Amount, Dropdown panel, Avatar group.
- Сетка L0–L3 сломана: L3 или L2–L3 переносятся (Date range panel, Overlay, Snack, Toast, Notification, Accordion, Chart card, Chart plot, Radio card, Pagination, Side panel, Tabs, Transaction, Dropdown panel); все уровни ужаты в одну колонку (Coin stack, Dot, Circle timer, Page indicator, Coin). ≈ 20.
- Показана не вся матрица (один-два варианта, без проблемных состояний): ≈ 40. Примеры: Calendar (только Single), Code cell, Select compact.

### 07 Группы и раскладка
- Иллюстрации не показывают заявленное (перенос без переноса, пустые карточки, обрезанная группа): Chip, Icon button, Radio.
- Раздел дублирует 09: Icon button.

### 08 Движение
- Цифры и события против контракта: ≈ 15. Примеры: Status, Step symbol, Counter, Badge, Page dot, Progress, Progress circle, Tab, Radio, Skeleton, Spinner.
- Пустой чип токена «–» (обычно у «Уменьшить движение»): все борды полного шаблона (≈ 20).
- «Не собрано: нет в описании» при наличии движения в контракте: ≈ 20. Примеры: Menu item, Select compact, Address.

### 09 Правила, 10 Доступность
- Тоньше контракта: нет «Не делаем», нет клавиатуры и ролей: ≈ 40. Примеры: Segmented, Select compact, Transaction, Tab.
- Одинаковые или ничего не показывающие иллюстрации «делаем / не делаем»: ≈ 8. Примеры: Spinner, Card, Page dot, Icon button.
- В «Доступности» пункты не про доступность: Calendar, Spinner.
- Пустой раздел «• —»: Tabs (10), Chart card (10), Table row (09).
- Карточки разной высоты в ряду: Tab, Code cell, Skeleton, Progress circle.

### 11 Код и токены
- Токены не из контракта или несуществующие (`space/6`, `focus/offset`, `control/border/hover`, `surface/raised`, `Elevation/2`): ≈ 35. Примеры: Segment, Radio, Menu, Tooltip.
- Размеры и отступы в строке «Цвет, обводка»; «Прочее» — простыня; нет размерных токенов `size/*`: ≈ 30. Примеры: Amount, Modal, Coin.
- Код родителя или чужого компонента, props не из контракта: Breadcrumb item, Page dot, Checkbox, Skeleton.
- Примеры Vue, Flutter и превью не совпадают: Tab, Chip, Radio, Code cell.
- Вложенные компоненты расходятся с контрактом (Icon button вместо `_Overlay surface`): Modal, Sheet, Calendar, Address, Password field.

### 12 Локали и RTL
- ar нигде не зеркален (пометка «RTL вручную»): все борды с разделом (≈ 60).
- Переводится один слот, остальное по-русски: ≈ 30. Примеры: Modal, Sheet, Side panel.
- Строки чужого компонента («Last 30 days», «Withdrawal address», «Insufficient funds», «Settings»): ≈ 25. Примеры: Tab, File upload, Transaction, Nav item.
- «short» — обрубок слова («Wit», «Las», «Con», «Ins») и одинокая ячейка в ряду: ≈ 30.
- Режимы локали не применились вовсе: Textarea, Input, Multiselect, Date range field, Password field, Select.
- «Не собрано: переводимых строк нет» при наличии строк и RTL в контракте: ≈ 12. Примеры: Dropdown panel, Avatar group, Chart metric, Pagination.

### «Не собрано в этой версии»
- «Нет в описании» там, где контракт описывает зоны и движение: ≈ 25. Примеры: Input amount, Menu item, Select compact.
- Раздела нет на бордах полного шаблона и старых бордах: ≈ 12. Примеры: Button, Tab, Chip, Radio.
- Дыры нумерации разделов (03 → 06, 04 → 06 → 09) без пояснения рядом: ≈ 30.
- Не сказано, что с борды выпали целые наборы (см. ниже).

### Служебные записки на бордах
- «Черновик собран автоматически… Пункты с пометкой «Предложение» написаны Claude» — в том числе на beta и там, где таких пунктов нет: ≈ 35. Примеры: Sheet, Calendar, Select.
- «Блок добавлен 2026-11-13… на просмотр Стефану (OPEN-QUESTIONS)»: ≈ 8. Примеры: Avatar, Icon button, Skeleton, Code cell.
- Зелёная плашка «Применено по рекомендации… Не согласен — скажи, откачу»: ≈ 10. Примеры: Multiselect option, Select, Amount, Transaction (на двух последних — устаревшая, про «Красный Debit»).
- «Борда пересобрана 2026-11-05: проверить», «Новый компонент по пробелам DS… проверить»: ≈ 8. Примеры: Segmented, Promo card, Coin.
- Подзаголовки «Предложение Claude: описание компонента этих правил не содержит» при заполненном контракте: ≈ 12. Примеры: Amount, Avatar group, Step.

### Состав и формат борд
- Страница с несколькими наборами показывает один: Badge / Counter, Empty state / Status screen, Progress / Progress circle / Spinner (три борды, каждая про один набор), Select / Select compact, Table (16 наборов на трёх бордах), Chart card / Chart plot, Status / Dot, Tab bar / Tab bar item, Input + 7 аддонов. ≈ 20 борд.
- Имя борды не совпадает с набором: Dot («Status»), Counter («Badge»), Key-value row («Payout summary»), Status screen («Empty state»), Spinner («Progress»).
- Beta-наборы на лёгком черновом шаблоне (буллеты вместо карточек, нет кода и чек-листа): ≈ 30. Примеры: Menu item, Avatar group, Address, Code input.
- Старый формат без шапки и 01–12, мусор экранирования HTML: Input 404:91, Textarea 353:1004, Tab bar 366:4725.
- Большие пустоты между разделами, сетки на половину ширины: ≈ 30. Примеры: Select, Amount, Modal.
- Текст-заглушка в образцах (Body, «Button», «[ Сохранить ]», иконка «+»): ≈ 15. Примеры: Modal, Sheet, Chip, Tooltip.
- Устаревшие имена: Active вместо Selected / Current (Nav item, Legend item, Step trail), State вместо Status (Notification), Snack внутри Toast, Debit (Table cell, Amount, Transaction), Banner вместо Suggest, Card вместо Promo card.
