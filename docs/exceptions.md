# Реестр исключений: значения без переменной

Правило DSP №2 и этап 2: **всё в Figma на переменных, кроме этого реестра.** Значение без токена допустимо, только если оно

1. следует из формулы или физики: радиус кольца фокуса = радиус контрола + 2, линия 1 px, зона нажатия, системный отступ ОС, размер данных графика; либо
2. это содержимое-заглушка, а не часть дизайна компонента.

Значение в двух и более местах — не исключение, оно получает токен. Каждая запись: значение, где, причина, дата пересмотра (после неё запись нужно подтвердить или заменить токеном; проверка `npm run exceptions` падает на просроченных).

Проверка «всё на переменных»: `scripts/figma/variables-check.plugin.js` (запуск через `use_figma` на Components, только чтение). Всё, что она находит и чего нет в таблице ниже, — дефект. Формат таблицы проверяет `scripts/exceptions-check.mjs`.
