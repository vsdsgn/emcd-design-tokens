# DS 2.0 → DSP (Design System Playground)

Источник: сообщение агента разработчика playbook (закреп в проекте DS, 2026-10-05). Обязательно к соблюдению.

## Что это
DSP — https://ds-playground.pv2.org (только из VPN), репо `multigeo/ds-playground` (code.emcdtech.com, VPN).
Генерирует из Figma код библиотеки `ui-emcd-web` (Vue): токены, иконки, компоненты. Источник правды — **только Figma**.

Читает:
- **Foundations** — переменные (через плагин DSP Export; REST без Enterprise их не отдаёт);
- **Components** — наборы, варианты, свойства, привязки к переменным, описания (REST);
- **Icons** — компоненты `icon/*` (REST, SVG).

## Правила (иначе конвейер ломается)
1. `Status: draft | beta | stable | deprecated` — **первой строкой** описания каждого компонента. Без строки = draft.
2. **Всё на переменных**: цвета, размеры, отступы (и gap), радиусы, обводки, типографика. Сырые значения DSP помечает ошибкой.
3. **Code syntax WEB** у каждой переменной = имя CSS-переменной (`var(--action-primary-default)`).
4. Переименование/удаление переменной, свойства, значения варианта (Type, Size, State…) = **major** для продуктов. Удалять только после `deprecated`; о переименовании — заранее предупредить разработку.
5. Единицы — в описании переменной: rem-примитивы «Npx · Xrem»; где неочевидно — указать (letter-spacing: px).
6. `layout/breakpoint-min` (Viewport) — DSP строит по нему media-запросы. Не удалять.
7. Описание и фрейм документации компонента совпадают с вариантами (типы, кольцо фокуса, код-API). При расхождении DSP верит вариантам.
8. Иконки: `icon/<имя>` в файле Icons, обводка привязана к `icon/stroke/regular`, цвет — к переменной.

## Порядок после изменений
1. Publish в Figma: `vX.Y.Z — что изменилось`.
2. Менялись переменные Foundations → **сразу после публикации**, **с включённым VPN**: плагин DSP Export в Foundations → «Токены» → `https://ds-playground.pv2.org` → «Отправить в DSP» → дождаться «Отправлено». Без VPN плагин пишет «Подключён VPN?» — включить и нажать ещё раз. До публикации не запускать. Пока сайт не принимает — «Скачать файл» и передать разработке.
3. Компоненты и иконки подтягиваются сами (VPN не нужен).
4. DSP открывает MR, проверяет и вливает разработка.

Плагин (один раз): Figma desktop → Plugins → Development → Import plugin from manifest → манифест из `multigeo/ds-playground`.

## Чек-лист перед публикацией
- [ ] `Status:` в первой строке у новых и изменённых компонентов
- [ ] нет непривязанных значений
- [ ] у новых переменных code syntax WEB и единица в описании
- [ ] ничего не переименовано/удалено без согласования (иначе сначала `deprecated`)
- [ ] описание и документация совпадают с вариантами
- [ ] менялись переменные → после публикации: VPN вкл → DSP Export → «Отправить в DSP»

## Аудит DS 2.0 по правилам DSP — 2026-10-05

- **Foundations** (720 переменных): у всех есть code syntax WEB в формате `var(--…)`; добавлен недостающий у 5 (`easing/standard`, `easing/out`, `scale/press`, `touch/is-coarse`, `touch/is-fine`). Единицы добавлены в описания `letter-spacing/*` (px · rem) и `type/*/line-height`. `layout/breakpoint-min` на месте. Примитивы размеров скрыты от публикации — компоненты привязываются только к семантике.
- **Components** (116 компонентов): `Status:` есть у всех; цвета (fill/stroke) привязаны у всех.
  Непривязанные размеры: привязано ~3 000 значений по точному совпадению с семантикой — `space/*` (gap, padding), `control/padding-x/*` (горизонтальные отступы корня у компонентов с Size), `radius/*` (Platform/Brand; кольцо фокуса 16 → `radius/focus-ring`), `border/width/default` (1), `border/width/focus` (2 у слоёв focus). В EMCD визуально без изменений; Geometria теперь получает свои радиусы.
- **Осталось без токена** (~1 700 значений) → нужны новые семантические токены (решение Стефана, см. OPEN-QUESTIONS):
  - gap 6 (~557: иконка↔подпись в контролах), 10 (36), 20 (4);
  - padding 6 (96), 10 (162), 14 (88), 20 (97), 28 (16), 40 (9), разовые 9/34/106;
  - radius 2 (201), 3 (57), 6 (59), 9 (24), 13 (12), 18 (8), 20 (14), 28 (4), 1 (8), 5 (5);
  - обводка 2 не у фокуса (71), 3 (12), 1.5 (5);
  - дробные (7.84, 19.6, 27.44 — масштаб Pressed у Floating button) — переделать на целые.
- **Icons** (121 компонент): все `icon/*`, обводка и цвет привязаны — чисто.
