# Цель 3: система конструкций, лейаутов и паттернов на Мониторинге и WL (поставлена 2026-11-21)

**Цель.** На экранах Мониторинга (Web + мобильный веб), WL B2B admin (Web) и WL B2C (клиент, App / мобильный веб) выстроить одну систему: отступы (шкала + правила «что каким интервалом»), лейауты экранов по платформам и продуктам, конструкции (организмы / виджеты) с правилами применения, паттерны взаимодействия (состояния, подтверждения, панели, фильтры, массовые действия). Атомы и молекулы — довести полировку (все варианты, состояния, отступы — на токенах, без расхождений Figma ↔ код). Собрать организмы → виджеты → страницы → разделы; экраны пересобраны из DS и сверены с production глазами; код повторяет экраны.

Почему эти продукты: у них похожие конструкции (сводка, график с периодом, таблица с фильтрами, детали объекта, настройки), но много отличий — на них система проверяется, а не подгоняется под один продукт.

Работаю автономно. Publish, `stable`, изменение существующих токенов Foundations — только Стефан (копится в «Очереди»). Экраны всех продуктов (Мониторинг, WL B2B / B2C) пересобираем в файлах Migration test: Web — в Web App, мобильные и App — в App (решение Стефана 21.11).

- **WL B2B admin** — Analytics, Users (список + профиль), Reports, Settings, Fee, Watcher-link (Web 1440).

## Решения «один способ» (по инвентарю, 21.11)
- **Каркас B2B** → Sidebar (как Web App и Мониторинг); глобальный Top bar admin, серый контейнер и вставка 12 — убираем; поиск — в Page header, язык и профиль — в подвал Sidebar.
- **Детали объекта:** Web — страница (с Tabs); Compact — Sheet. Широкий Modal (Мониторинг 1156) не используем.
- **Фильтры:** до 4 в строке над таблицей; больше — Side panel (Web) / Sheet (Compact). Modal для фильтров не используем.
- **Период:** Chip в Chart card; глобальный период страницы — Chip в тулбаре (не Segmented).
- **Модалки:** только `size/modal/sm` 400 (подтверждение) и `md` 560 (короткая форма); 7 ширин макетов → 2.
- **Подтверждение:** заголовок-вопрос, объект в тексте, [Отмена Secondary] [Действие Primary / Danger], без иллюстраций.
- **Действия строки:** 1 — Icon button Ghost; 2+ — ⋯ Menu; удаление — только в Menu.
- **Массовые действия:** новый **Bulk action bar** («Выбрано N из M» + до 3 Button + ⋯ + закрыть), не колонка кнопок.
- **Сводка по статусам:** новый **Fleet summary** (числа + Progress по сегментам + Legend item со счётчиком); Gauge не вводим.
- **Итог таблицы:** Table row Variant=Total первой строкой (не отдельной карточкой снизу).
- **Раскрытие строки на Compact:** List item / Transaction → Sheet деталей (контракт Transaction), без аккордеона.
- **Key-value:** без пунктирного лидера.
- **Load more:** Button Secondary M по центру; Pagination — только отчёты.
