# Типографика и локализация интерфейсов (черновик, 2026-10-05)

Основа — [Редполитика общая](https://emcd-io.atlassian.net/wiki/spaces/MRKTNG/pages/2388656283) и Tone of Voice (Confluence). Этот документ — интерфейсный слой поверх них: что делает DS и код, чтобы правила соблюдались сами, на всех языках. Расхождения с Редполитикой — в конце, на решение.

## Языки

Сейчас в переключателе: English, Русский, Português, Español, Deutsch, العربية, Nederlands, Norsk, Қазақша, हिन्दी, Bahasa Indonesia, Türkçe, ไทย, Tiếng Việt, 日本語, Українська, Slovenščina, Polski, Italiano. Не все дошли до продукта, но интерфейс обязан их выдерживать.

Следствия для DS:
- **RTL** — арабский: зеркальная раскладка, логические отступы (`margin-inline-start`), стрелки и «назад» зеркалятся, графики и числа — нет. Адреса, суммы, тикеры — изоляция направления (`<bdi>` / `unicode-bidi: isolate`).
- **Письменности** — латиница, кириллица, арабская, деванагари, тайская, японская. Интерфейсный шрифт не покрывает всё → стек с Noto Sans для арабской, деванагари, тайской, японской (см. п. 9 OPEN-QUESTIONS — выбор шрифта).
- **Высота строки** — тайский и деванагари выше: межстрочный у них +10–20 %, контейнеры не обрезают выносные элементы (`overflow` не `hidden` по вертикали у текста).
- **Длина** — немецкий, нидерландский, португальский длиннее английского на 30–40 %: кнопки и табы не фиксированной ширины, перенос или обрезка с тултипом.
- **Переносы** — японский и тайский без пробелов: `word-break` по правилам языка, `lang` на корне обязателен.

## Главное правило: форматирует код, а не руки

Числа, проценты, валюты, даты, время, единицы — только через CLDR: `Intl.NumberFormat`, `Intl.DateTimeFormat`, `Intl.RelativeTimeFormat` в вебе, пакет `intl` во Flutter. Ни одного ручного разделителя, пробела или знака в шаблонах строк. Так каждый язык получает свою норму автоматически.

| Что | ru | en | de | tr | ar |
|---|---|---|---|---|---|
| Число | 1 234 567,89 | 1,234,567.89 | 1.234.567,89 | 1.234.567,89 | 1,234,567.89 (латинские цифры) |
| Процент | 5 % | 5% | 5 % | %5 | 5% |
| Валюта USD | 1 234,50 $ | $1,234.50 | 1.234,50 $ | $1.234,50 | — |

**Проценты** — как в CLDR для языка: в русском и немецком с неразрывным пробелом, в английском слитно, в турецком знак впереди. Это и есть «универсально международно».

**Крипто-суммы** — CLDR не знает тикеров, поэтому компонент **Amount**: число по локали + неразрывный пробел + тикер (`0,12345678 BTC` / `0.12345678 BTC`). Точность по монете: стейблкоины — 2 знака, BTC и монеты — 8, без отбрасывания значимых нулей там, где сумма — баланс. Табличные цифры (`font-variant-numeric: tabular-nums`). Сокращения (`1,2 млн`, `1.2M`) — `notation: 'compact'`.

**Знак суммы** — настоящий минус U+2212, плюс; для изменений баланса — через `signDisplay: 'exceptZero'`.

**Адреса и почта** — сокращение по Редполитике (6 + ••• + 6), моноширинный или табличный шрифт, изоляция направления в RTL.

**Даты и время** — `Intl.DateTimeFormat` с локалью; год только если не текущий (Редполитика); часовой пояс — из настроек пользователя, в интерфейсе не подписываем.


## Решения Стефана (2026-10-05)

- Макеты в Figma — только ru и en. Все переводы живут в Crowdin.
- Правила — универсальные (форматирует CLDR), а к ToV и Редполитике добавляем таблицы по локалям (ниже — сгенерировано, `node scripts/l10n-table.mjs`).
- Арабский — **латинские цифры**: локаль `ar-u-nu-latn`.
- Время — в часовом поясе пользователя (задаётся в настройках); сам пояс в интерфейсе не подписываем, он виден только в настройках.
- Тайский — **григорианский календарь** (`th-u-ca-gregory`): по умолчанию CLDR даёт буддийский год (2569 вместо 2026).
- Минус — показываем U+2212 (`−30`): CLDR для большинства локалей отдаёт дефис-минус, обёртка форматирования заменяет его.

Особенности, которые видно по таблице:
- **Хинди** группирует по-индийски: `12,34,567.89`, сокращения — лакх и крор (`12 लाख`).
- **Испанский, польский, итальянский, словенский** не ставят разделитель в четырёхзначных числах (`1234,50`) — норма CLDR.
- **Турецкий** ставит знак процента впереди (`%12,5`).
- **Японский** сокращает по десяткам тысяч (`120万`).
- **Арабский** — CLDR сам добавляет метки направления (LRM/RLM) вокруг чисел; не вырезать.


## Шрифты (решение 2026-10-05)

- **Base / fallback для всех — Inter + Noto по письменностям, если и они не загрузились — системный шрифт** (решение 2026-10-05). IBM Plex Mono — только цифры и таблицы в отдельных случаях (Numeric). Inter (OFL): WL Default на Inter; в CSS за брендовым шрифтом всегда идёт Inter, затем системный стек и Noto по письменностям: Noto Sans Arabic, Noto Sans Devanagari, IBM Plex Sans Thai, Noto Sans JP.
- EMCD — Roobert PRO (вопрос замены на бесплатный открыт); Geometria — PP Neue Montreal, как в продукте (в брендбуке BB+ указан Onest — расхождение; проверить коммерческую лицензию Pangram Pangram).
- Inter покрывает латиницу (вкл. вьетнамский, турецкий), кириллицу (вкл. казахский, украинский), греческий. Не покрывает арабскую, деванагари, тайскую, японскую — их закрывает Noto в стеке (так задумано и у самого Noto: семья из отдельных шрифтов по письменностям).

## Инструменты: где правило проверяется само

1. **Figma** — плагин Typograf (у дизайнеров) + проверки в скилле ux-copy: типограф по локали макета, формат чисел, кавычки языка, обращение на «вы» (Mining) / «ты» (Coinhold Wallet).
2. **Сборка переводов и CMS (Strapi)** — прогон строк через `typograf` (npm, MIT) с локалью языка; ошибки — в лог сборки.
3. **Crowdin** — собственная проверка качества (QA check) с теми же правилами — переводчик видит ошибку до выгрузки.
4. **Код** — линтер: запрет ручных разделителей и знаков валют в строках; только Intl / Amount.

Typograf поддерживает не все 19 языков — для неподдерживаемых проверяем только числа и кавычки через CLDR.

## Расхождения с Редполитикой — на решение

| Редполитика сейчас | Предлагаем для интерфейсов | Почему |
|---|---|---|
| Дробную часть отделяем точкой, `0.5 ETH` (во всех языках) | По локали: `0,5 ETH` в ru/de/es/…; точка в en | 19 языков, у большинства запятая; CLDR делает сам |
| `100%` без пробела | По CLDR: `100 %` ru/de, `100%` en, `%100` tr | Решение Стефана: «как надо, международно» |
| `$ 1 000` знак впереди с тонким пробелом | По CLDR: `1 000 $` ru, `$1,000` en | Иначе ручная вёрстка на каждый язык |
| `− 30 USDT` минус с пробелом | `−30 USDT` — знак вплотную | Международная норма, `signDisplay` |
| Числа меньше 10 — словами | В интерфейсе — цифрами; словами только в маркетинге | Сканируемость, перевод |
| Английские кавычки ‘одинарные‘ (в примере обе открывающие) | “Двойные” в американском английском; в интерфейсе названия кнопок без кавычек | Ошибка в примере + норма en-US |
| «МСК» / «GMT+3» | Часовой пояс пользователя из настроек, без подписи в интерфейсе (решено) | Международная аудитория |

## OpenType: интерфейс без лигатур (решение 2026-10-05)

Интерфейсный текст — буквально то, что набрано: `->` остаётся `->`, `1x2` — `1x2`, адреса кошельков, хэши и суммы не подменяются глифами.

- **Выключено везде:** `liga` (стандартные лигатуры), `clig`, `calt` (контекстные замены: стрелки, ×, выравнивание двоеточий у Inter), `dlig`.
- **Табличные цифры (`tnum`)** — в таблицах, суммах, балансах, таймерах, хэшрейте: колонки не прыгают при смене значений.
- **Web:** `build/css/type-features.css` — на `:root` `font-variant-ligatures: none` и `font-feature-settings: var(--font-features-ui)`; для цифр `[data-numeric="tabular"]` или `font-feature-settings: var(--font-features-tabular)`. Поля ввода и кнопки шрифт не наследуют — в компонентах `font-feature-settings: var(--font-features-ui)` явно.
- **Flutter:** в базовом `TextStyle` — `fontFeatures: [FontFeature.disable('liga'), FontFeature.disable('clig'), FontFeature.disable('calt'), FontFeature.disable('dlig')]`; для чисел добавить `FontFeature.tabularFigures()`.
- **Figma:** в Plugin API свойства OpenType только для чтения — выставляется руками в текстовых стилях Foundations: Type details → Details → Ligatures: выкл (Standard + Contextual alternates) — во всех; Numbers: Tabular figures — в стилях `Tabular/*`.
- **У Roobert PRO нет табличных цифр** (в Figma → Details → Numbers нет Spacing). Поэтому числа с tnum — шрифтом `font/family/numeric` (брендовый токен; EMCD, WL — Inter; Geometria — Inter, пока не проверены tnum у PP Neue Montreal). Slashed zero у Roobert есть.
- **Какой стиль для чисел:** `Tabular/*` (font/family/numeric + tnum) — суммы, балансы, таблицы, таймеры, хэшрейт — по умолчанию; `Numeric/*` (IBM Plex Mono) — особые случаи: адреса, хэши, ID транзакций, где важно посимвольное выравнивание и различие 0/O. Состав Tabular: Display LG, Heading MD, Body MD, Body SM, Label MD, Label SM, Caption.
