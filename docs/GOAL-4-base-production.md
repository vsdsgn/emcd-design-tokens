# Цель 4: Base-набор DS 2.0 в production-состоянии (поставлена 26.11)

**Цель.** Стиль Base доведён до production по уровням: атомы и молекулы → организмы и виджеты → конструкции → лейауты и экраны. У каждого уровня есть правила сборки для людей (борда, страница «Как собрать») и для агентов (manifest, бриф, проверки). Источник требований — аудит миграции 9 продуктов в общем файле (924 экрана, ~12 тыс. замен, `docs/migration/component-map-all.csv`).

**Production-ready компонент** = контракт + борда v3 + код React / Vue + все состояния и оси проверены + на экранах продуктов стоит **без ручных переопределений** (аудит переопределений = 0 или исключение с причиной) + правило «когда / когда нет». Статус `stable` ставит Стефан.
