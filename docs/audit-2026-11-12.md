## 1. Figma ↔ правила

### 1.1. Статус и описание
- `Status:` не первой строкой: Card (первая строка «Card — Атом-шаблон»); нет совсем: Dot, `_Tooltip arrow`.
- Beta по описанию (20): Badge, Counter, Breadcrumb item, Button, Checkbox, Chip, Icon button, Radio, Segment, Status, Tab, Toggle, Input, Input addon ×5 (Unit, Max, Chevron, Stepper, Counter), Textarea, Tab bar item. Эмодзи страницы и `Status:` расходятся там, где на странице несколько наборов (Input addon / Clear и / Icon без `Level:`, Dot без статуса на beta-странице Status).
- Нет раздела «Когда использовать» у 56 наборов (все Table cell, группы Checkbox / Radio / Toggle, Step*, Code cell, Date cell, Page dot, Pagination item, Avatar group, Input addon, Address, Notification, Password field, Transaction, Status screen, File upload и др.). Нет `A11y:` у 45 (Avatar, Divider, Spinner, Step*, группы, Table cell, Textarea, Tabs и др.).
- Порядок разделов описания разный (A11y до «Когда использовать» у 15 наборов), лишние заголовки («Токены:», «Тень:», «Expressive (привязано):»).

### 1.2. Оси и имена
- `Left | Right` вместо `Start | End`: Checkbox, Radio, Toggle (`Control`), Table header cell, Table cell / Text (`Align`), Button (`Icon left`, `Icon right`). Решение 09.11 не выполнено.
- Порядок значений `Size` разный: `M|S` (Checkbox, Radio, Toggle, Table cell / Coin, группы), `L|M` (Accordion, List item, Code cell), `M|L|XL|S` (Tab, Tabs), `L|M|S` (Empty state), `Large|Compact` (Page header).
- Порядок `State`: Skeleton первым (Badge, Table header cell); Pressed после Disabled (Segment, Accordion, Radio card, Multiselect option, Date cell, Select compact, Input amount).
- Булевы оси: `Selected=Off|On`, `Open=Off|On`, `Network=Off|On`, но `Filled=False|True` (Input amount), `Presets=On|Off`, `Border=On|Off`.
- Имена булевых свойств: «Show X» и просто «X» вперемешку (`Icon`, `Close`, `Divider`, `Counter`, `Actions`, `Timer` против `Show label`, `Show leading`). «Safe area» (Toast, Tab bar) против «Safe margin» (остальные).
- Одна задача, разные оси: выбранность `Status=Off|On` (Checkbox, Radio, Toggle, Radio card) против `Selected=Off|On` (Chip, Segment, Tab) против `State=Selected` (Multiselect option, Pagination item, Nav item, Legend item, Table row) против свойства `Selected` (Menu item). Ошибка `Tone=Danger` (Checkbox, Radio) против `State=Error` (поля, группы).
- Loading: ось State у Icon button, Input, Select, Textarea; булево свойство у Button.
- Страница ≠ набор: Multiselect → Multiselect option; Payout summary → Key-value row; Stepper → Step; Header → Page header; Navigation → Sidebar.
