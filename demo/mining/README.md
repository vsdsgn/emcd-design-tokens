## Как запустить

```bash
npm run demo:mining            # все 15 экранов
npm run demo:mining -- mw-workers web-history   # выборочно
```

Скрипт `shots.mjs` раздаёт репо своим http-сервером, открывает страницы в Playwright Chromium (установленный, `deviceScaleFactor` 1), пишет `out/<экран>.png` и `out/compare-<экран>.png` (макет | код | разница `difference`); для дашборда Web — ещё `out/web-dashboard-hover.png` (указатель на ~60 % ширины графика, без сравнения: в макетах hover нет); в «Истории» Web проверяет, что клик по «Периоду» открывает панель, а Esc закрывает. `out/` в `.gitignore`. Ошибка или предупреждение в консоли страницы — провал.
Посмотреть в браузере: любой статический сервер из корня репо → `/demo/mining/web-dashboard.html`.

## Загрузка (patterns 3.11a, 19.11)

`web-dashboard.html?state=loading` и `mw-dashboard.html?state=loading` — те же экраны в загрузке: Sidebar / Top bar, табы разделов, меню экрана (монета, периоды графика), «Подключить», промо и Action bar живые; данные — State=Skeleton компонентов: Amount L (значение + фиат), Coin, Chart metric, Legend item, Chart plot Line + Bars, Status summary (Stat card Tone=Neutral); факты без своего Skeleton — кирпич `Skeleton` Text по ширине ожидаемого текста (подписи остаются).
`shots.mjs` снимает `out/web-dashboard-loading.png`, `out/mw-dashboard-loading.png` (пульс остановлен) и сверяет высоты блоков с загруженной страницей — сводка, факты, карточка графика, показатели, легенда, область графика, плитки статусов, ряд графика / сводка статусов; расхождение больше 1 px — провал. Результат 19.11: 12 + 12 блоков, совпадают (на Web плитки тянутся по высоте графика — реальная проверка плиток — на мобильном: 104 / 104).

## Заглушки

- **Шрифты.** Roobert PRO и IBM Plex Mono лицензионные, в репо их нет. На стенде скриншотов подставлены Liberation Sans / Liberation Mono (близкие метрики; `@font-face` только в `shots.mjs`; отключить — `DEMO_REAL_FONTS=1`). Ширина текста отличается на 1–5 %.
- **Логотип** — текст «EMCD» / «E» (в Figma — `logo (placeholder)`).
- **Картинки промо** (сайдбар «14%», «Забусти свой майнинг») — нейтральная заглушка Promo card (`emcd-promo__image--placeholder`).
- **ETH, BEL, LKY, PEP** — нет в Symbols кода (`btc, kas, ltc, doge`): Coin рисует нейтральный круг с буквой.
- **Данные графика** — подобраны на глаз под макет.

## Калькулятор, Watcher-link, Настройки (19.11)

Собраны из `window.EMCD`: заголовки секций — `SectionHeader` (M «Переводить на Coinhold», S «Сколько переводить?», «Прогноз доходности», M «Типы уведомлений»), карточка Coinhold — `Card` `ambientLight` (Level 2 на Web, Level 1 на мобильном), итог дохода — `Amount` XL `tone="success"`; поля — Input M On border с единицей в Trailing; период и доля — ряд Chip M (выбор одного); прогноз — Progress S (первый accent, второй success) + Amount S; монеты — Coin + Amount (S на Web в 2 колонки, M на мобильном); «Время выплат» — Key-value row; VIP — Suggest Strip Neutral. Watcher-link: Card M на ссылку, срок — Progress S по тону остатка, Badge S «Основной», Toggle без подписи (`inputProps.aria-label`), Icon button Ghost S `link` / `more-horizontal`; выключенная — тексты `text-tertiary`. Настройки: заголовки колонок — Checkbox M с подписью и описанием, ячейки — Checkbox без подписи с `aria-labelledby` (колонка + строка), «Настроить» — Button Text XS.
Заголовок страницы («Калькулятор доходности», «Мои Watcher link») — `PageHeader` Large (`h1`, Heading/XL, сверху `space-8`). У Watcher-link два Select — фильтры экрана, не Actions (контракт: до двух кнопок), поэтому шапка без действий стоит в ряду меню вместе с Select и «Создать Watcher link», как на макете. В `shots.mjs` экраны «вся высота» снимаются с окном во всю страницу — Action bar (sticky) встаёт в конец, как на макете.
