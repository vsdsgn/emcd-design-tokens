# Action bar

🟡 Beta (20.11) — можно брать в макеты и код. Нижняя панель действий мобильного веба: 1–2 Button M поровну, прилипает к низу («Подключить / Создать группу», «Фильтры / Выгрузить»). Контракт — `docs/components/action-bar.md`.

**Ось (как в Figma «Action bar»):** Actions 1 · 2; свойство Badge (19.11). Подложка `surface/level-0`, поля 16 сверху и по бокам, снизу 24 (`space/24`; замер экранов Figma: высота 80 = 16 + 40 + 24) или 16 + safe area — что больше, зазор 8. Одно действие — Primary; два — Tertiary.

**Badge (19.11):** бейдж автодействия — Badge S Neutral Subtle «A» (`badgeText`) над последней кнопкой, справа сверху (top −высота / 2, конец −4): «Выгрузить» с автовыгрузкой. Только с `actions`.

**Правила:** не на экранах с Tab bar и не на Web (там действия в шапке или тулбаре).

**Доступность:** порядок фокуса — после контента.

Классы: `emcd-action-bar`; с бейджем — `emcd-action-bar__slot` (последняя кнопка) и `emcd-action-bar__badge`.
