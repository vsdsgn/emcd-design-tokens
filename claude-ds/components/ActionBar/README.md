# Action bar

Нижняя панель действий мобильного веба: 1–2 Button M поровну, прилипает к низу («Подключить / Создать группу», «Фильтры / Выгрузить»).

**Ось (как в Figma «🟠 Action bar»):** Actions 1 · 2. Подложка `surface/level-0`, поля 16 сверху и по бокам, снизу 24 (`space/24`; замер экранов Figma: высота 80 = 16 + 40 + 24) или 16 + safe area — что больше, зазор 8. Одно действие — Primary; два — Tertiary.

**Правила:** не на экранах с Tab bar и не на Web (там действия в шапке или тулбаре).

**Доступность:** порядок фокуса — после контента.

Классы: `emcd-action-bar`.
