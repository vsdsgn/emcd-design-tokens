# Chart tooltip

Тултип точки графика: дата и время сверху, под ними строки «маркер серии — название — значение». Не подсказка к элементу интерфейса (это Tooltip).

**Оси (как в Figma «🟡 Chart tooltip»):** Rows 1–4 (в коде — длина `rows`), Show date (`showDate`). Карточка `surface/raised`, обводка `border/default`, `radius/sm`, тени; ширина 168–320. Дата и время — body-sm `text-tertiary`; серия — label-sm Medium `text-secondary` с Legend swatch; значение — label-sm Medium `text-primary` по концу строки.

**Правила:** серий больше четырёх — 4 главные и «+N»; значение вне нормы — `tone: 'danger' | 'warning'`. Шрифт — текста: моно только у подписей осей графика (17.11). Дата и серия — одна строка до 200 с многоточием.

**Поведение:** показывает и ставит график: справа от перекрестия, у края — слева или прижат к границе области, курсор не перекрывает. Esc — скрыть.

**Доступность:** `role=status`, `aria-live=polite`; в Chart plot тултип `aria-hidden`, озвучивает сам график (одна живая область). Серия всегда текстом, не только цветом.

Классы: `emcd-chart-tooltip`, `__header`, `__date`, `__time`, `__row`, `__label`, `__series`, `__value [--danger|--warning]`, `__more`.
