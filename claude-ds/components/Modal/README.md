# Modal

Окно поверх страницы: короткое действие или подтверждение, которое прерывает поток (удалить, подтвердить вывод, 2FA, выбор).

**Оси (как в Figma «🟡 Modal»):** Header — Title (заголовок-действие) · Coin (монета 32 + название + строка «тикер · сеть») · Empty (только крестик, заголовок в Body); Footer — Single (одна кнопка) · Stacked (две стопкой, главная сверху) · Horizontal (две в ряд, отмена слева, главная справа) · None. Свойства: Divider (линия под шапкой, когда Body прокручивается или начинается со списка), Show close (Off — только на необратимом шаге).

**Форма:** подложка `surface-level-1`, обводка `border-subtle`, радиус `radius-surface` 24, отступы 32; заголовок Display/MD 28 Bold; кнопки XL 56 на всю ширину. Ширина — `size-modal-sm` · `md` (560) · `lg` по содержимому. Под окном — затемнение `surface-overlay`.

**Когда нет:** детали объекта или длинная форма — Side panel / Sheet; сообщение без решения — Toast / Alert; на Compact (App, мобильный веб) — Sheet.

**Правила:** одна задача и одно главное действие на окно; опасное действие — Button Tone Danger; модал поверх модала не открываем; Header=Empty всегда с крестиком.

**Движение:** fade + масштаб 0.96 → 1, 200 мс (App 320), закрытие 150 мс; при reduced motion — только fade.

**Доступность:** `role="dialog"`, `aria-modal="true"`, `aria-labelledby` на заголовок; фокус заперт внутри; Esc и клик по затемнению закрывают (кроме необратимых шагов); фокус возвращается на кнопку вызова; крестик — Icon button «Закрыть».

Классы: `emcd-modal [emcd-modal--{sm|lg}]` → `__header` (`__title`, `__heading` + `__coin` + `__desc` для Coin, `__close`) → `[__divider]` → `__body` → `__footer [__footer--horizontal]`.
