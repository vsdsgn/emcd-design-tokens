# Skeleton

Кирпич загрузки: строка текста, заголовок, круг или блок на месте контента, у которого нет своего State=Skeleton (строки списков, факты).

**Оси (как в Figma «🟡 Skeleton»):** Shape Text · Title · Circle · Rect.

**Когда какой:** форма — по будущему контенту: Text 12 — строка текста, Title 20 — заголовок, Circle — аватар, монета, иконка, Rect — картинка, график, блок; ширина — как у ожидаемого текста (`width`).

**Когда нет:** у компонента есть свой State=Skeleton (Amount, Chart metric, Key-value row, Stat card, Chip, Legend item, Chart plot, Table cell / header cell, Coin, Avatar, Badge, поля) — берём его; до 300 мс — ничего, 300 мс–1 с — Spinner; у кнопки скелетона нет.

**Правила (patterns 3.11a):** каркас экрана живой, скелетон — только данные; высота блока при загрузке не меняется (кирпич — inline-block по центру строки текста, строка сохраняет высоту). Все скелетоны экрана пульсируют синхронно (прозрачность, 1.2 с); «Уменьшить движение» — статично.

**Доступность:** кирпич декоративен (`aria-hidden`); у контейнера — `aria-busy="true"`.

Классы: `emcd-skeleton [emcd-skeleton--{title|circle|rect}]`.
