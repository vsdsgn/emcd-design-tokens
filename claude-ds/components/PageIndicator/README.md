# Page indicator

Точки карусели 2–5: текущая вытянутая. Промо, онбординг, сторис-баннеры.

**Оси (как в Figma «🟡 Page indicator»):** Count 2–5 × Selected 1–5. Точка 6 (`size/dot/sm`), `icon/tertiary`; текущая — 16, `control/checked`; зазор 6; смена — 200 мс.

**Правила:** больше 5 слайдов — счётчик «3 / 12». Точки кликабельны (`onSelect`), только если есть свайп или стрелки, иначе декоративны. Место — по центру под каруселью, отступ 12.

**Доступность:** озвучивается «Слайд 3 из 5»; кликабельные точки — кнопки с именем и зоной нажатия ≥ 24.

Классы: `emcd-page-indicator`, `emcd-page-dot` (текущая — `[aria-current="true"]`).
