# Top bar

Шапка мобильного веба: логотип, аккаунт, баланс (копейки `text-tertiary`) и «Меню». Над Tabs M разделов.

**Ось (как в Figma «🟠 Top bar»):** Platform Mobile web (App — следующим вариантом); Logo, Account, Balance, Cents, Show balance. Подложка `surface/level-0`, поля 8 / 16, зазор 12; аккаунт и баланс — label-lg + шеврон 16; «Меню» — Icon button Ghost M.

**Правила:** draft — только корневые экраны мобильного веба; Web — Sidebar; App — Top bar App (план).

**Доступность:** «Меню» — кнопка с подписью; баланс — одной фразой («Баланс $123 456.78»).

Классы: `emcd-top-bar`, `__logo`, `__account`, `__name`, `__balance`, `__amount`, `__cents`, `__menu`.
