# Bulk action bar (draft, 22.11)

Полоса массовых действий над выбранными строками таблицы: «Выбрано N из M», до двух действий, «⋯» — остальные (удаление — там, с подтверждением), «Снять выбор» (и Esc). Мониторинг «Устройства», B2B Users.

```jsx
<BulkActionBar count={2} total={120} actions={[{ label: 'Перевести в ожидание' }, { label: 'Сменить площадку' }]} onMore={openMenu} onClear={clear} />
```
